Работа со строками

Режем, ищем, заменяем и красиво оформляем текст.

Цель урока

Научиться работать с текстом: брать символы и срезы, менять регистр, искать и заменять, убирать лишние пробелы, разрезать строку на слова и склеивать обратно, проверять состав строки и форматировать вывод в f-строках.

Время: около 45 минут · 2 упражнения в уроке · тест · 4 задачи на дом

Зачем это нужно

Текст — самые частые данные в программах: имена и пароли, сообщения в чатах, адреса, поисковые запросы, содержимое файлов. Почти любая программа что-то делает с текстом: проверяет, что email содержит «@», убирает лишние пробелы из введённого имени, ищет слово в документе, красиво оформляет чек.

Со строками вы уже знакомы. В этом уроке вы научитесь по-настоящему с ними работать: разрезать, искать, заменять и форматировать.

Строка — последовательность символов

Строка устроена похоже на список: у каждого символа есть индекс, начиная с нуля. Работают len(), срезы и перебор циклом:

word = "Программа"

print(len(word))
print(word[0], word[-1])
print(word[:5])
print(word[::-1])

for ch in "кот":
    print(ch * 3)

Но есть важное отличие: строку нельзя изменить. Нельзя заменить в ней одну букву, как в списке. Все методы строк не меняют исходную строку, а возвращают новую.

Большие и маленькие буквы

name = "аННа сМирнова"

print(name.upper())
print(name.lower())
print(name.capitalize())
print(name.title())
print(name)

Последняя строка показывает: сама name не изменилась. Чтобы сохранить результат, его кладут в переменную: name = name.title().

Это часто используют, чтобы сравнивать без учёта регистра: answer.lower() == "да" сработает и для «Да», и для «ДА».

Убираем лишние пробелы

Пользователи часто случайно ставят пробелы в начале или в конце ввода. Метод strip() убирает их с обеих сторон (а заодно и переносы строк):

raw = "   Максим   "
print("[" + raw + "]")
print("[" + raw.strip() + "]")

Разрезать и склеить: split и join

split() разрезает строку на список кусочков. Без аргументов — по пробелам, а можно указать любой разделитель. join() делает обратное: склеивает список строк в одну, вставляя между ними разделитель:

sentence = "Python это просто"
words = sentence.split()
print(words)
print("Слов:", len(words))

date = "11.11.2026"
day, month, year = date.split(".")
print("Год:", year)

print("-".join(["2026", "11", "11"]))
print(" + ".join(["1", "2", "3"]))

Обратите внимание: join вызывается у разделителя, а список передаётся в скобках: "-".join(список). Склеивать можно только строки.

Проверки: из чего состоит строка

print("2026".isdigit())
print("12a".isdigit())
print("Python".isalpha())
print("Hello World".isalpha())
print("   ".isspace())

isdigit() особенно полезен перед int(): сначала проверить, что пользователь ввёл только цифры, и только потом превращать в число. Пробел — не буква, поэтому "Hello World".isalpha() даёт False.

Форматирование в f-строках

В f-строке после значения можно поставить двоеточие и указать, как его оформить. Самое полезное — количество знаков после точки и ширина колонки:

price = 1234.5
print(f"Цена: {price:.2f} руб.")
print(f"Скидка: {0.15:.0%}")

items = [("Хлеб", 45), ("Молоко", 89), ("Сыр", 320)]
for name, cost in items:
    print(f"{name:<10}{cost:>6} руб.")
ЗаписьЧто значит
{x:.2f}2 знака после точки
{x:.0%}в процентах
{s:<10}выровнять по левому краю, ширина 10
{n:>6}выровнять по правому краю, ширина 6

Специальные символы и многострочный текст

Внутри строки обратная косая черта \ начинает специальный символ: \n — перенос строки, \t — табуляция, \" — кавычка внутри строки. А текст в тройных кавычках может занимать несколько строк:

print("Первая строка\nВторая строка")
print("Имя:\tАнна")
print("Он сказал: \"Привет\"")

poem = """Python — язык простой,
Учится легко,
Код читается как текст."""
print(poem)

Частые ошибки новичков

Ошибаться — нормально, так учатся все программисты. Главное — научиться читать сообщение об ошибке: Python подсказывает, что не так и в какой строке.

Пытаемся изменить букву

Так нельзя
word = "кит"
word[0] = "К"
Правильно
word = "кит"
word = "К" + word[1:]
print(word)

Python скажет: TypeError: 'str' object does not support item assignment

Строки неизменяемы. Соберите новую строку и положите её в ту же переменную.

Индекс за концом строки

Так нельзя
code = "AB"
print(code[2])
Правильно
code = "AB"
print(code[-1])

Python скажет: IndexError: string index out of range

В строке из двух символов индексы 0 и 1. Последний символ надёжнее брать как code[-1].

Опечатка в названии метода

Так нельзя
name = "анна"
print(name.uper())
Правильно
name = "анна"
print(name.upper())

Python скажет: AttributeError: 'str' object has no attribute 'uper'

У строк нет метода uper — Python сообщает, что такого атрибута нет. Проверьте написание: upper.

join со списком чисел

Так нельзя
nums = [1, 2, 3]
print("-".join(nums))
Правильно
nums = [1, 2, 3]
print("-".join(str(n) for n in nums))

Python скажет: TypeError: sequence item 0: expected str instance, int found

join склеивает только строки. Сначала превратите числа в строки.

Главное за урок

  • Строка — последовательность символов: работают индексы, срезы, len() и перебор for. Изменить строку нельзя — методы возвращают новую.
  • upper, lower, title меняют регистр, strip убирает пробелы по краям.
  • in, find, count, replace, startswith, endswith — поиск и замена.
  • split() режет строку на список, "-".join(список) склеивает обратно.
  • f-строки умеют форматировать: {x:.2f} — два знака после точки. \n — перенос строки.
