Урок 9: Работа со строками

Изучаем методы строк, форматирование и полезные приёмы работы с текстом.

🎯 Цель урока

Научиться работать со строками: изменять регистр, искать, заменять, разделять и форматировать текст.

📝 Основы строк

Строки в Python - это текст в кавычках. Можно использовать одинарные или двойные кавычки:

text = "Привет, мир!"
print(text)

# Многострочная строка - тройные кавычки:
poem = """Первая строка
Вторая строка
Третья строка"""
print(poem)

🔠 Методы изменения регистра

text = "python"
print(text.upper())       # Верхний регистр: PYTHON
print(text.lower())       # Нижний регистр: python
print(text.capitalize())  # Первая буква заглавная: Python

🔍 Поиск и замена

text = "python"
print(text.replace("y", "i"))  # Заменяет символы: pithon

sentence = "Я люблю Python"
print(sentence.find("Python"))   # Возвращает индекс начала: 8
print("Python" in sentence)      # Проверяет наличие: True

Метод replace('что', 'на что') заменяет все вхождения первой подстроки на вторую.

📏 Длина строки

text = "python"
print(len(text))  # Длина строки: 6

Функция len() - это встроенная функция (не метод!), она возвращает количество символов в строке.

✂️ Разделение и объединение строк

words = "apple,banana,orange".split(",")
print(words)  # ['apple', 'banana', 'orange']

# Объединение списка строк в одну:
print(" - ".join(words))  # apple - banana - orange

Метод split(разделитель) разбивает строку на список подстрок по указанному разделителю. Метод join(список) - обратная операция.

🧹 Очистка строк от лишних пробелов

Метод strip() удаляет пробелы и невидимые символы строго по краям строки (начало и конец):

messy = "   Привет!   "
clean = messy.strip()
print(clean)  # Выведет: Привет!

💬 Форматирование строк (f-строки)

Современный и удобный способ вставить переменные в строку - f-строки (f-strings). Поставьте букву f перед кавычками и вставляйте переменные в фигурные скобки:

name = "Алекс"
age = 25
print(f"Привет! Меня зовут {name} и мне {age} лет.")
# Выведет: Привет! Меня зовут Алекс и мне 25 лет.

🔤 Многострочные строки и escape-символы

Тройные кавычки позволяют создавать строки, которые занимают несколько строк кода. Escape-символы — специальные последовательности, задающие невидимые символы внутри строки:

# Многострочные строки (тройные кавычки)
poem = """
Программирование — это искусство,
Python — язык без барьеров,
Код — это мысль в чистом виде.
"""
print(poem)

# Escape-символы
print("Первая строка\nВторая строка")  # \n — перенос строки
print("Колонка 1\tКолонка 2")          # \t — табуляция
print("Это \"цитата\" в строке")       # \" — кавычка внутри
print("Путь: C:\\Users\\Documents")    # \\ — обратный слэш

🔍 Методы поиска и проверки

Python предоставляет богатый набор методов для поиска подстрок и проверки содержимого строки:

text = "Привет, мир! Python — отличный язык."

# Поиск
print(text.find("Python"))       # 14 — индекс начала
print(text.find("Java"))         # -1 — не найдено
print("Python" in text)          # True
print(text.startswith("Привет")) # True
print(text.endswith("язык."))    # True
print(text.count("а"))           # Сколько раз встречается "а"

# Проверка содержимого
age = "25"
name = "Алекс"
print(age.isdigit())      # True — только цифры?
print(name.isalpha())     # True — только буквы?
print("abc123".isalnum()) # True — буквы и цифры?

✂️ Форматирование и обработка

Методы join(), split(), strip() и методы выравнивания делают обработку текстовых данных удобной и лаконичной:

# join() — соединение списка в строку
words = ["Python", "это", "здорово"]
sentence = " ".join(words)
print(sentence)  # Python это здорово

# Разделение и очистка
csv_line = "  Алекс,25,Москва  "
cleaned = csv_line.strip()  # Убираем пробелы по краям
parts = cleaned.split(",")  # Разбиваем по запятой
print(parts)  # ['Алекс', '25', 'Москва']

# Выравнивание
name = "Боб"
print(name.ljust(10, "."))  # "Боб......."  — влево
print(name.rjust(10, "."))  # ".......Боб"  — вправо
print(name.center(10, "-")) # "---Боб----" — по центру

📝 Практический пример: обработка данных

Рассмотрим реальную задачу: нормализация «грязной» строки с данными пользователя — привести имя к нужному виду, извлечь число и очистить название города:

# Парсинг строки с данными пользователя
raw_data = "  алеКСАНДр иВАНов,   25 лет,   г. Москва  "

parts = raw_data.split(",")
name_raw, age_raw, city_raw = parts

name = " ".join(word.capitalize() for word in name_raw.strip().split())
age = int(''.join(filter(str.isdigit, age_raw)))
city = city_raw.strip().replace("г. ", "")

print(f"Имя: {name}")    # Александр Иванов
print(f"Возраст: {age}") # 25
print(f"Город: {city}")  # Москва
