Модули и библиотеки

Подключаем готовый код: математика, случайности и тысячи библиотек.

Цель урока

Научиться подключать модули через import и from … import, пользоваться модулями math, random, statistics и collections, узнать, как устанавливать сторонние библиотеки через pip и как создать свой модуль.

Время: около 40 минут · 2 упражнения в уроке · тест · 3 задачи на дом

Зачем это нужно

Программисты почти никогда не пишут всё с нуля. Нужно случайное число для игры, квадратный корень, текущая дата, работа с таблицами или сайтами — для всего этого уже есть готовый код, проверенный миллионами людей.

Такой готовый код хранится в модулях. Модуль — это файл с функциями, который можно подключить к своей программе одной строкой. С Python поставляются сотни модулей (их называют стандартной библиотекой), а ещё сотни тысяч можно скачать бесплатно. Умение пользоваться модулями — одно из главных умений программиста.

Подключаем модуль: import

Чтобы использовать модуль, его подключают словом import в начале программы. Потом функции модуля вызывают через точку: модуль.функция(). Начнём с модуля math — математика:

import math

print(math.sqrt(16))
print(math.pi)
print(math.ceil(4.1))
print(math.floor(4.9))
print(math.pow(2, 10))

math.sqrt(x)квадратный кореньmath.sqrt(25) → 5.0
math.piчисло π3.141592653589793
math.ceil(x)округлить вверхmath.ceil(4.1) → 5
math.floor(x)округлить внизmath.floor(4.9) → 4

Сколько нужно автобусов

Программа получает два числа: сколько учеников едет на экскурсию и сколько мест в одном автобусе. Выведите, сколько нужно автобусов. Неполный автобус — тоже автобус.

Подсказка

Разделите обычным делением people / seats и округлите вверх: math.ceil(...).

from … import: только нужное

Если из модуля нужны одна-две функции, их можно подключить напрямую. Тогда имя модуля перед функцией писать не нужно:

from math import sqrt, pi

print(sqrt(81))
print(round(pi, 2))

А ещё модулю можно дать короткое имя-псевдоним словом as. Так принято делать с длинными названиями — например, библиотеку для таблиц pandas почти все подключают как import pandas as pd:

import statistics as st

grades = [5, 4, 4, 5, 3, 5]
print("Среднее:", round(st.mean(grades), 2))
print("Медиана:", st.median(grades))
print("Чаще всего:", st.mode(grades))

Модуль random: случайности

Модуль random нужен для игр, викторин, жеребьёвок и тестов. Запустите пример несколько раз — результат каждый раз будет разным:

import random

print("Кубик:", random.randint(1, 6))
print("Монетка:", random.choice(["орёл", "решка"]))

cards = ["валет", "дама", "король", "туз"]
random.shuffle(cards)
print("Перемешали:", cards)

print("Победители:", random.sample(["Аня", "Борис", "Вика", "Гоша", "Дима"], 2))
ФункцияЧто делает
random.randint(a, b)случайное целое от a до b включительно
random.choice(список)случайный элемент списка
random.shuffle(список)перемешать список (меняет сам список)
random.sample(список, k)k разных случайных элементов
random.random()случайное дробное число от 0 до 1

from collections import Counter

words = "кот пёс кот рыба кот пёс".split()
counts = Counter(words)
print(counts)
print("Самое частое:", counts.most_common(1))

Расстояние между точками

Программа получает одну строку с четырьмя числами через пробел: x1 y1 x2 y2 — координаты двух точек. Выведите расстояние между ними, округлённое до 2 знаков после точки.

Подсказка

Расстояние — корень из суммы квадратов разностей: math.sqrt((x2 - x1) ** 2 + (y2 - y1) ** 2). Не забудьте round(..., 2). Строка map(float, input().split()) уже превратила все четыре числа в дробные.

Сторонние библиотеки и pip

Кроме стандартной библиотеки, есть огромный каталог бесплатных библиотек от других программистов — PyPI (pypi.org). Их устанавливают программой pip, которая идёт вместе с Python. Команду пишут в терминале, а не в программе:

pip install requests

После установки библиотеку подключают обычным import. Несколько популярных:

  • requests — запросы к сайтам и API (урок 16);
  • pygame — 2D-игры;
  • pandas и matplotlib — таблицы и графики;
  • aiogram — Telegram-боты;
  • flask — сайты.

Больше библиотек с описаниями — на странице «Библиотеки». Сторонние библиотеки в примерах на этом сайте не работают — их нужно ставить на своём компьютере.

Виртуальное окружение. Когда у вас появится несколько проектов, для каждого удобно создавать отдельное «окружение» со своим набором библиотек: python -m venv venv. Так библиотеки разных проектов не будут мешать друг другу. Пока вы учитесь, можно обойтись без него.

Свой модуль

Любой ваш файл .py — тоже модуль. Если программа стала большой, полезные функции выносят в отдельный файл и подключают их через import. Оба файла должны лежать в одной папке:

def greet(name):
    return f"Привет, {name}!"

def square(n):
    return n * n
import helpers

print(helpers.greet("Аня"))
print(helpers.square(7))
Не называйте свои файлы как модули Python. Если назвать файл random.py или math.py, то import random подключит ваш файл вместо настоящего модуля, и всё сломается.

Частые ошибки новичков

Ошибаться — нормально, так учатся все программисты. Главное — научиться читать сообщение об ошибке: Python подсказывает, что не так и в какой строке.

Забыли import

Так нельзя
print(math.sqrt(16))
Правильно
import math
print(math.sqrt(16))

Python скажет: NameError: name 'math' is not defined

Модуль нужно подключить до использования. Добавьте import math в начало программы.

Функция без имени модуля

Так нельзя
import math
print(sqrt(16))
Правильно
import math
print(math.sqrt(16))

Python скажет: NameError: name 'sqrt' is not defined

После import math функции вызываются через точку: math.sqrt. Без имени модуля можно, только если подключить функцию через from math import sqrt.

Опечатка в названии модуля

Так нельзя
import maths
Правильно
import math

Python скажет: ModuleNotFoundError: No module named 'maths'

Модуля с таким именем нет. Проверьте написание. Если это сторонняя библиотека — возможно, её нужно сначала установить через pip.

randint с одним числом

Так нельзя
import random
print(random.randint(6))
Правильно
import random
print(random.randint(1, 6))

Python скажет: TypeError: Random.randint() missing 1 required positional argument: 'b'

randint нужны два числа: начало и конец диапазона.

Главное за урок

  • Модуль — файл с готовыми функциями. Подключение: import math, вызов: math.sqrt(16).
  • from math import sqrt подключает функцию напрямую, import statistics as st даёт короткое имя.
  • random.randint(a, b), choice, shuffle — случайности для игр и викторин.
  • Стандартная библиотека уже есть в Python. Сторонние библиотеки ставятся командой pip install имя в терминале.
  • Свой файл .py тоже можно подключить через import. Не называйте файлы именами модулей Python.
