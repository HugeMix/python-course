Урок 12: Модули и библиотеки

Изучим, как подключать модули и использовать готовые библиотеки в Python.

🎯 Цель урока

Научиться использовать встроенные модули и сторонние библиотеки, подключать нужные инструменты с помощью import и устанавливать новые пакеты через pip.

📌 Что такое модуль?

Модуль - это файл с готовым кодом Python (.py), который можно подключить в свою программу с помощью ключевого слова import. В Python огромное количество встроенных модулей - они уже установлены и готовы к использованию.

🔧 Подключение встроенных модулей

Пример: модуль math содержит математические функции:

import math

print(math.sqrt(25))  # Квадратный корень → 5.0
print(math.pi)        # Константа π → 3.141592653589793
print(math.ceil(4.1)) # Округление вверх → 5

🎯 Импорт конкретных функций - from ... import

Можно импортировать только нужные функции из модуля. Тогда не нужно каждый раз писать название модуля через точку:

from math import pi, sqrt

print(sqrt(16))  # Выведет 4.0
print(pi)        # Выведет 3.141592653589793

🎲 Модуль random - случайные числа

Встроенный модуль random используется для генерации случайных чисел:

import random

print(random.randint(1, 10))  # Случайное целое число от 1 до 10
print(random.random())        # Случайное число от 0.0 до 1.0

fruits = ["яблоко", "банан", "вишня"]
print(random.choice(fruits))  # Случайный элемент из списка

📦 Установка сторонних библиотек - pip

pip (Package Installer for Python) - это официальный менеджер пакетов Python. С его помощью можно в одну команду в терминале загрузить и установить любую стороннюю библиотеку из интернета:

pip install requests

После установки библиотеку можно использовать как обычный модуль:

import requests

response = requests.get("https://api.github.com")
print(response.status_code)  # Выведет 200, если запрос успешен

💡 Псевдоним при импорте - as

Длинному имени модуля можно дать короткий псевдоним с помощью ключевого слова as:

import math as m

print(m.sqrt(9))  # 3.0 - всё так же, но через псевдоним `m`

📦 Создание своего модуля

Любой файл с расширением .py является модулем в Python. Вы можете разбить проект на несколько файлов и импортировать нужные функции и переменные из одного файла в другой — так код становится организованнее и удобнее для повторного использования:

# --- Файл mymath.py ---
PI = 3.14159265

def circle_area(radius):
    """Площадь круга"""
    return PI * radius ** 2

def circle_perimeter(radius):
    """Длина окружности"""
    return 2 * PI * radius

# --- Файл main.py ---
import mymath

area = mymath.circle_area(5)
print(f"Площадь: {area:.2f}")

# Или импортируем конкретные имена:
from mymath import circle_area, PI
print(f"Площадь: {circle_area(5):.2f}")
print(f"π = {PI}")

🌐 Полезные стандартные модули

Стандартная библиотека Python содержит сотни готовых модулей. Вот наиболее часто используемые в реальных проектах:

# os — работа с операционной системой
import os
print(os.getcwd())                     # Текущая директория
os.makedirs("new_dir", exist_ok=True)  # Создать папку

# sys — системные параметры
import sys
print(sys.version)   # Версия Python
print(sys.platform)  # Платформа (win32, linux, darwin)

# json — работа с JSON
import json
data = {"name": "Алекс", "age": 25}
json_str = json.dumps(data, ensure_ascii=False)  # Объект → строка JSON
print(json_str)  # {"name": "Алекс", "age": 25}

loaded = json.loads(json_str)  # Строка JSON → объект
print(loaded["name"])  # Алекс

# re — регулярные выражения
import re
text = "Телефон: +7 (999) 123-45-67"
phone = re.findall(r'\d+', text)
print(phone)  # ['7', '999', '123', '45', '67']

🏠 Виртуальное окружение

Виртуальное окружение (virtual environment) — это изолированная копия Python со своим набором установленных пакетов. Это позволяет разным проектам использовать разные версии одной библиотеки, не мешая друг другу и не засоряя системный Python:

# Создание виртуального окружения
python -m venv myproject_env

# Активация (Windows)
myproject_env\Scripts\activate

# Активация (Mac/Linux)
source myproject_env/bin/activate

# Установка пакетов (только в этом окружении)
pip install requests

# Сохранение списка зависимостей
pip freeze > requirements.txt

# Установка из файла зависимостей (для других разработчиков)
pip install -r requirements.txt

# Деактивация
deactivate

Файл requirements.txt — стандарт Python-проектов. Он перечисляет все необходимые библиотеки с их версиями, чтобы любой разработчик мог воспроизвести окружение одной командой pip install -r requirements.txt. Всегда добавляйте папку виртуального окружения в .gitignore, а requirements.txt — в репозиторий.
