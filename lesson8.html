Словари и множества

Ищем данные не по номеру, а по названию, и убираем повторы.

Цель урока

Научиться хранить данные парами «ключ → значение», безопасно искать, добавлять и удалять их, перебирать словарь циклом, считать частоту значений и работать с множествами: убирать повторы, находить общее и разное.

Время: около 45 минут · 2 упражнения в уроке · тест · 4 задачи на дом

Зачем это нужно

В списке значения хранятся по номерам: нулевой, первый, второй. Но часто удобнее искать не по номеру, а по названию. В телефонной книге вы ищете номер по имени, в меню кафе — цену по названию блюда, в словаре — перевод по слову.

Для этого в Python есть словари (dict): они хранят пары «ключ → значение». А ещё в этом уроке — множества (set): наборы без повторов, которые умеют быстро находить общее и разное.

Создаём словарь

Словарь пишут в фигурных скобках. Каждая пара — это ключ, двоеточие и значение; пары разделяют запятыми:

menu = {"чай": 50, "кофе": 120, "булочка": 70}

print(menu)
print(menu["кофе"])
print("Позиций в меню:", len(menu))

Значение достают по ключу в квадратных скобках: menu["кофе"]. Ключи в словаре не повторяются — у каждого ключа одно значение. Ключом обычно бывает строка или число, а значением — что угодно, хоть список.

Добавляем, меняем, удаляем

stock = {"яблоки": 10, "груши": 5}

stock["бананы"] = 7       # новый ключ — добавится
stock["яблоки"] = 12      # старый ключ — значение заменится
stock["груши"] -= 2       # можно менять как переменную
del stock["бананы"]       # удалить пару

print(stock)

Запись словарь[ключ] = значение работает в обе стороны: если такого ключа не было — пара добавится, если был — значение заменится.

Безопасный поиск: in и get

Если попросить ключ, которого нет, Python выдаст ошибку KeyError. Поэтому перед поиском часто проверяют наличие ключа через in или используют метод get — он вернёт значение по умолчанию вместо ошибки:

menu = {"чай": 50, "кофе": 120}

print("чай" in menu)
print("сок" in menu)

print(menu.get("кофе"))
print(menu.get("сок"))
print(menu.get("сок", 0))

Телефонная книга

В программе уже есть словарь с контактами. Программа получает имя. Выведите номер этого человека, а если такого имени в книге нет — Нет такого контакта.

Подсказка

Проверьте if name in phones: и выведите phones[name], иначе — сообщение. Или одной строкой: print(phones.get(name, "Нет такого контакта")).

Перебор словаря

Цикл for по словарю перебирает ключи. Чтобы получать сразу ключ и значение, используют метод items():

grades = {"Аня": 5, "Борис": 4, "Вика": 5}

for name in grades:
    print(name)

for name, grade in grades.items():
    print(f"{name}: {grade}")

print("Все оценки:", list(grades.values()))
print("Средняя:", sum(grades.values()) / len(grades))
МетодЧто возвращает
d.keys()все ключи
d.values()все значения
d.items()пары (ключ, значение)
d.get(k, x)значение по ключу k, а если его нет — x
d.pop(k)удаляет ключ k и возвращает его значение

Подсчёт: словарь-счётчик

Одна из самых полезных задач для словаря — посчитать, сколько раз встречается каждое значение. Ключ — то, что считаем, значение — сколько раз встретилось:

votes = ["кот", "пёс", "кот", "хомяк", "кот", "пёс"]

counts = {}
for v in votes:
    counts[v] = counts.get(v, 0) + 1

print(counts)

counts.get(v, 0) берёт текущее число голосов, а если такого ключа ещё нет — 0. К нему прибавляется 1, и результат кладётся обратно.

Множества: наборы без повторов

Множество (set) — набор значений, где каждое встречается только один раз, а порядок не важен. Его тоже пишут в фигурных скобках, но без двоеточий. Самый частый приём — убрать повторы из списка:

cities = ["Москва", "Казань", "Москва", "Сочи", "Казань"]
unique = set(cities)

print(unique)
print("Разных городов:", len(unique))

unique.add("Омск")
print("Сочи" in unique)

Порядок элементов множества может отличаться от порядка в исходном списке — множеству порядок не важен. Если нужен порядок, превратите множество в отсортированный список: sorted(unique).

Операции с множествами

Множества умеют находить общие и разные элементы — как круги Эйлера на уроке математики:

anna = {"футбол", "шахматы", "рисование"}
boris = {"шахматы", "плавание", "футбол"}

print("Общие:", sorted(anna & boris))
print("Все вместе:", sorted(anna | boris))
print("Только у Анны:", sorted(anna - boris))
ЗнакНазваниеРезультат
a & bпересечениеэлементы, которые есть в обоих
a | bобъединениевсе элементы из обоих
a - bразностьесть в a, но нет в b

Общие друзья

Программа получает две строки: друзей Ани и друзей Бориса — имена через пробел. Выведите общих друзей через пробел в алфавитном порядке. Если общих нет — Нет общих друзей.

Подсказка

Общие — это anna & boris. Отсортируйте через sorted(), а склеить список в строку через пробел можно так: " ".join(список).

Словарь из словарей

Значением словаря может быть другой словарь или список. Так хранят сложные данные — например, анкеты учеников:

students = {
    "Аня": {"возраст": 14, "оценки": [5, 4, 5]},
    "Борис": {"возраст": 15, "оценки": [4, 4, 3]},
}

print(students["Аня"]["возраст"])
for name, info in students.items():
    avg = sum(info["оценки"]) / len(info["оценки"])
    print(name, round(avg, 1))

Частые ошибки новичков

Ошибаться — нормально, так учатся все программисты. Главное — научиться читать сообщение об ошибке: Python подсказывает, что не так и в какой строке.

Нет такого ключа

Так нельзя
ages = {"Аня": 14}
print(ages["Петя"])
Правильно
ages = {"Аня": 14}
print(ages.get("Петя", "нет данных"))

Python скажет: KeyError: 'Петя'

Ключа «Петя» в словаре нет. Проверьте его через in или используйте get.

{} — это пустой словарь, а не множество

Так нельзя
tags = {}
tags.add("python")
Правильно
tags = set()
tags.add("python")
print(tags)

Python скажет: AttributeError: 'dict' object has no attribute 'add'

Пустые фигурные скобки создают словарь. Пустое множество создаётся только так: set().

Обращение к множеству по индексу

Так нельзя
colors = {"red", "green"}
print(colors[0])
Правильно
colors = {"red", "green"}
print(sorted(colors)[0])

Python скажет: TypeError: 'set' object is not subscriptable

У множества нет порядка, а значит, нет и номеров. Проверяйте наличие через in или превратите множество в список.

Список в роли ключа

Так нельзя
points = {}
points[[1, 2]] = "A"
Правильно
points = {}
points[(1, 2)] = "A"
print(points)

Python скажет: TypeError: unhashable type: 'list'

Ключ словаря не должен меняться, а список изменяемый. Используйте кортеж — он неизменяемый.

Главное за урок

  • Словарь хранит пары «ключ → значение»: {"чай": 50}. Значение достают по ключу: menu["чай"].
  • d[k] = v добавляет или заменяет, del d[k] удаляет. Нет ключа — KeyError, поэтому используйте in или get.
  • Перебор: for k, v in d.items():. Подсчёт: counts[x] = counts.get(x, 0) + 1.
  • Множество — набор без повторов: set(список) убирает дубликаты. Пустое множество — set(), а не {}.
  • & — общие элементы, | — все вместе, - — разница.
