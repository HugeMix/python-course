Урок 5: Циклы (for, while)

Изучаем, как повторять действия в коде с помощью циклов.

🎯 Цель урока

Научиться использовать циклы for и while для повторения действий, а также управлять ходом цикла с помощью break и continue.

🔄 Цикл for - когда количество повторений известно

Цикл for используется тогда, когда заранее известно количество повторений или есть последовательность элементов для перебора.

for i in range(5):
    print("Привет, мир!")

Этот код 5 раз напечатает «Привет, мир!».

📐 Функция range()

Функция range() генерирует последовательность чисел. Важно знать:

  • range(5) генерирует числа от 0 до 4 (т.е. 0, 1, 2, 3, 4). Число 5 не включается!
  • range(1, 6) - от 1 до 5 включительно.
  • range(0, 10, 2) - чётные числа от 0 до 8 (шаг 2).
for i in range(1, 6):
    print(i)  # Выведет: 1, 2, 3, 4, 5

🔁 Цикл while - пока условие истинно

Цикл while выполняется пока его условие истинно (True). Используется когда заранее неизвестно, сколько раз нужно повторить действие.

count = 0
while count < 5:
    print("Повтор №", count)
    count += 1

Этот код будет выполняться, пока count меньше 5. После каждой итерации (count += 1) значение увеличивается. Когда count станет равным 5 - условие станет ложным и цикл остановится.

⚠️ Осторожно: бесконечный цикл! Если условие никогда не станет ложным, цикл будет работать вечно и «заморозит» программу. Всегда следите, чтобы условие когда-нибудь стало False.

⏹️ Оператор break - досрочный выход из цикла

break немедленно прерывает цикл полностью и переходит к коду после него:

for i in range(10):
    if i == 5:
        break  # Остановит цикл при i = 5
    print(i)
# Выведет: 0, 1, 2, 3, 4

⏩ Оператор continue - пропуск итерации

continue пропускает оставшуюся часть текущей итерации и переходит к следующей. В отличие от break - цикл не останавливается, продолжает работу:

for i in range(10):
    if i % 2 == 0:
        continue  # Пропустит чётные числа
    print(i)
# Выведет: 1, 3, 5, 7, 9 (только нечётные)

📏 range() с шагом и отрицательным шагом

Функция range() принимает три параметра: range(start, stop, step). Шаг может быть как положительным, так и отрицательным — это позволяет считать в обратном направлении или перебирать только каждый N-й элемент.

# range(start, stop, step)
for i in range(0, 10, 2):
    print(i)  # 0, 2, 4, 6, 8 — чётные числа

for i in range(10, 0, -1):
    print(i)  # 10, 9, 8, ... 1 — обратный отсчёт

# Сумма чисел от 1 до 100
total = 0
for i in range(1, 101):
    total += i
print(total)  # 5050

🔁 Перебор коллекций

Цикл for умеет перебирать не только числа, но и любые последовательности: списки, строки, кортежи. Встроенная функция enumerate() позволяет одновременно получать индекс и значение элемента.

# Перебор списка
fruits = ["яблоко", "банан", "вишня"]
for fruit in fruits:
    print(fruit)

# Перебор строки (каждый символ)
word = "Python"
for char in word:
    print(char)

# enumerate() — индекс + значение
for index, fruit in enumerate(fruits):
    print(f"{index + 1}. {fruit}")
# 1. яблоко
# 2. банан
# 3. вишня

🪺 Вложенные циклы

Циклы можно вкладывать друг в друга. Внутренний цикл выполняется полностью для каждой итерации внешнего. Это полезно для обработки двумерных данных, таблиц или рисования фигур.

# Таблица умножения
for i in range(1, 4):
    for j in range(1, 4):
        print(f"{i} x {j} = {i*j}")
    print("---")  # Разделитель после каждой строки

# Вывод прямоугольника из звёздочек
rows = 4
cols = 6
for row in range(rows):
    for col in range(cols):
        print("*", end="")  # end="" не переносит строку
    print()  # Перенос строки после каждой строки звёздочек

🎮 Практический пример: угадай число

Объединим цикл while, ввод пользователя и оператор break в полноценную мини-игру. Программа будет продолжать задавать вопрос до тех пор, пока игрок не угадает секретное число.

import random

secret = random.randint(1, 100)
attempts = 0

print("Угадай число от 1 до 100!")

while True:
    guess = int(input("Твоё число: "))
    attempts += 1

    if guess < secret:
        print("Больше!")
    elif guess > secret:
        print("Меньше!")
    else:
        print(f"Верно! Угадал за {attempts} попыток!")
        break
