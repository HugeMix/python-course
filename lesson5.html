Циклы: for и while

Учим программу повторять действия — 10 раз, 1000 раз или пока что-то верно.

Цель урока

Научиться повторять действия с помощью циклов for и while, использовать range(), считать суммы в цикле, перебирать буквы строки и управлять циклом через break и continue.

Время: около 45 минут · 2 упражнения в уроке · тест · 4 задачи на дом

Зачем это нужно

Представьте, что нужно вывести числа от 1 до 100. Можно написать сто строк с print… но программисты так не делают. Для повторения есть циклы: вы один раз описываете действие и говорите, сколько раз его повторить.

Циклы повсюду: игра каждую долю секунды заново рисует экран, музыкальный плеер проигрывает песни из списка одну за другой, банк начисляет проценты каждый месяц. В Python два вида циклов: for — когда заранее известно, сколько раз повторять, и while — когда повторять нужно, «пока что-то верно».

Цикл for и range()

Самый частый вариант — повторить действие нужное количество раз:

for i in range(5):
    print("Привет!", i)

Читается так: «для каждого i из ряда чисел от 0 до 5 — выполни то, что ниже с отступом». Как и в условиях, в конце строки ставится двоеточие, а повторяемые действия пишутся с отступом 4 пробела.

Переменная i на каждом повторе получает следующее число: 0, 1, 2, 3, 4. Обратите внимание: range(5) начинается с нуля и не включает 5. Повторов всё равно ровно пять.

Возможности range()

В range можно указать начало, конец и шаг:

ЗаписьКакие числаОбъяснение
range(5)0, 1, 2, 3, 4от 0 до 5, не включая 5
range(1, 6)1, 2, 3, 4, 5от 1 до 6, не включая 6
range(0, 10, 2)0, 2, 4, 6, 8с шагом 2
range(5, 0, -1)5, 4, 3, 2, 1обратный отсчёт: шаг −1
 
for n in range(1, 6):
    print(n, "в квадрате =", n ** 2)

print("Обратный отсчёт:")
for n in range(3, 0, -1):
    print(n)
print("Пуск!")

Копим результат в цикле

Очень частый приём: до цикла завести переменную-«копилку», а в цикле что-то к ней прибавлять. Так считают суммы, количество, очки.

total = 0
for n in range(1, 11):
    total += n
print("Сумма чисел от 1 до 10:", total)

Копилка total создаётся до цикла. Если написать total = 0 внутри цикла, она будет обнуляться на каждом повторе.

Программа получает число N. Выведите квадраты чисел от 1 до N, каждый на своей строке.

Подсказка

Нужен for i in range(1, n + 1): — плюс один, потому что конец в range не включается. Внутри цикла — print(i ** 2).

Перебор строки

Цикл for умеет перебирать не только числа. Например, можно пройти по буквам слова — переменная цикла по очереди получит каждую букву:

word = "Python"
for letter in word:
    print(letter)

В уроке 6 вы так же будете перебирать списки: имена, оценки, покупки.

Цикл while: «пока»

while повторяет действия, пока условие верно. Перед каждым повтором Python заново проверяет условие, и как только оно стало ложным — цикл заканчивается.

money = 90
day = 0

while money > 0:
    money -= 30
    day += 1
    print("День", day, "- осталось денег:", money)

print("Деньги кончились за", day, "дня")

while удобен, когда заранее неизвестно, сколько будет повторов: пока пользователь не введёт правильный пароль, пока в игре остались жизни, пока не кончились деньги.

Осторожно, бесконечный цикл. Если условие в while никогда не станет ложным, цикл будет крутиться вечно. Чаще всего это значит, что внутри цикла забыли изменить переменную. На этом сайте такой код остановится сам через 10 секунд.

break и continue

Двумя словами можно управлять циклом изнутри:

  • break — немедленно выйти из цикла;
  • continue — пропустить остаток этого повтора и сразу перейти к следующему.
for n in range(1, 10):
    if n == 3:
        continue
    if n == 6:
        break
    print(n)

Число 3 пропущено, а на 6 цикл закончился. Часто break используют вместе с while True — «повторять всегда», пока изнутри не прозвучит break:

while True:
    password = input("Пароль: ")
    if password == "python":
        print("Доступ открыт")
        break
    print("Неверно, попробуйте ещё раз")

Сумма до нуля

Программа получает целые числа, каждое на своей строке. Последнее число — 0: это знак, что ввод закончен. Выведите сумму всех чисел.

Подсказка

Используйте while True:. Внутри: прочитайте число, если оно равно 0 — break, иначе прибавьте его к total. После цикла выведите total.

Цикл внутри цикла

Внутрь одного цикла можно положить другой. Внутренний цикл будет полностью выполняться на каждом повторе внешнего. Так рисуют таблицы и узоры:

for row in range(1, 4):
    for col in range(1, 6):
        print(row * col, end=" ")
    print()

print(..., end=" ") выводит значение и ставит после него пробел вместо перехода на новую строку. А пустой print() после внутреннего цикла переводит строку.

Частые ошибки новичков

Ошибаться — нормально, так учатся все программисты. Главное — научиться читать сообщение об ошибке: Python подсказывает, что не так и в какой строке.

Забыли двоеточие

Так нельзя
for i in range(3)
    print(i)
Правильно
for i in range(3):
    print(i)

Python скажет: SyntaxError: expected ':'

Как и в if, в конце строки с for или while нужно двоеточие.

Нет отступа

Так нельзя
for i in range(3):
print(i)
Правильно
for i in range(3):
    print(i)

Python скажет: IndentationError: expected an indented block after 'for' statement on line 1

Действия, которые повторяются, должны быть сдвинуты на 4 пробела. Без отступа Python не понимает, что относится к циклу.

Текст вместо числа в range

Так нельзя
n = input()
for i in range(n):
    print(i)
Правильно
n = int(input())
for i in range(n):
    print(i)

Python скажет: TypeError: 'str' object cannot be interpreted as an integer

range работает только с целыми числами, а input() вернул строку. Превратите ввод в число через int().

Главное за урок

  • for i in range(n): повторяет действия n раз; i идёт от 0 до n − 1.
  • range(start, stop, step): конец не включается, шаг может быть отрицательным.
  • while условие: повторяет, пока условие верно. Следите, чтобы оно когда-нибудь стало ложным.
  • break — выйти из цикла, continue — перейти к следующему повтору.
  • Копилку (total = 0) создают до цикла, а в цикле к ней прибавляют. После строки с for/while — двоеточие и отступ.
