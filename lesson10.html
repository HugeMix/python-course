Файлы: запись и чтение

Сохраняем данные, чтобы они не пропадали после закрытия программы.

Цель урока

Научиться записывать данные в текстовые файлы и читать их обратно: выбирать режим открытия, работать через with open, читать файл по строкам, сохранять числа и разбирать простые таблицы CSV.

Время: около 45 минут · 2 упражнения в уроке · тест · 4 задачи на дом

Зачем это нужно

Всё, что программа хранит в переменных, исчезает, как только она закончила работу. Закрыли игру — и рекорд пропал. Чтобы данные сохранялись, их записывают в файлы.

Файлы нужны постоянно: сохранения в играх, настройки программ, заметки, списки контактов, отчёты и таблицы. В этом уроке вы научитесь записывать данные в текстовые файлы и читать их обратно.

Как это работает на сайте. Примеры на этой странице создают файлы во временной памяти браузера: после перезагрузки страницы они исчезнут. Когда вы запустите такую же программу на своём компьютере, файл появится в той же папке, где лежит программа.

Записываем и читаем файл

Работа с файлом всегда идёт в три шага: открыть, прочитать или записать, закрыть. В Python для этого используют конструкцию with open(...) — она сама закроет файл, когда блок с отступом закончится:

with open("hello.txt", "w", encoding="utf-8") as f:
    f.write("Привет, файл!\n")
    f.write("Это вторая строка\n")

with open("hello.txt", "r", encoding="utf-8") as f:
    text = f.read()

print(text)

Разберём строку with open("hello.txt", "w", encoding="utf-8") as f:

  1. "hello.txt" — имя файла;
  2. "w" — режим: write, «запись»;
  3. encoding="utf-8" — кодировка. Без неё русские буквы на некоторых компьютерах превратятся в «кракозябры» — всегда указывайте её;
  4. as f — открытый файл будет доступен под именем f.

f.write() записывает строку и не добавляет перенос строки сам — поэтому в конце мы пишем \n.

Режимы открытия

РежимЧто делаетЕсли файла нет
"r"чтение (режим по умолчанию)ошибка FileNotFoundError
"w"запись: стирает старое содержимоесоздаёт новый файл
"a"дозапись в конец, старое сохраняетсясоздаёт новый файл
Осторожно с режимом "w". Он сначала очищает файл. Если нужно добавить строку к уже записанным, используйте "a".
with open("log.txt", "w", encoding="utf-8") as f:
    f.write("Программа запущена\n")

with open("log.txt", "a", encoding="utf-8") as f:
    f.write("Пользователь вошёл\n")
    f.write("Пользователь вышел\n")

with open("log.txt", encoding="utf-8") as f:
    print(f.read())

Чтение по строкам

Обычно файл обрабатывают строка за строкой. Цикл for по файлу выдаёт его строки по очереди. У каждой строки в конце есть невидимый перенос \n — его убирают методом strip():

with open("pets.txt", "w", encoding="utf-8") as f:
    f.write("кот\nпёс\nхомяк\n")

with open("pets.txt", encoding="utf-8") as f:
    for line in f:
        print(repr(line), "→", line.strip())

repr() показывает строку «как есть», вместе с \n. Если не убрать перенос, при выводе через print между строками появятся лишние пустые строки.

Список покупок

Программа получает число N, а потом N покупок. Запишите их в файл shopping.txt — каждую с новой строки. Затем откройте файл, прочитайте и выведите покупки с номерами: 1. хлеб, 2. молоко и так далее.

Подсказка

Запись: f.write(input() + "\n"). Чтение: заведите счётчик num = 1, в цикле for line in f: печатайте f"{num}. {line.strip()}" и увеличивайте счётчик.

Числа в файле

В текстовом файле всё хранится как текст. Поэтому числа при записи превращают в строку (str()), а при чтении — обратно в число (int() или float()):

scores = [120, 340, 95, 410]

with open("scores.txt", "w", encoding="utf-8") as f:
    for s in scores:
        f.write(str(s) + "\n")

loaded = []
with open("scores.txt", encoding="utf-8") as f:
    for line in f:
        loaded.append(int(line))

print("Прочитали:", loaded)
print("Рекорд:", max(loaded))

Ещё два удобных способа прочитать файл: f.read().split() — сразу список всех слов или чисел-строк, и f.readlines() — список всех строк.

Таблицы: формат CSV

CSV — простой формат таблиц: каждая строка файла — строка таблицы, значения разделены запятыми. Такие файлы открываются в Excel и Google Таблицах. Прочитать CSV можно уже знакомым split(","):

with open("class.csv", "w", encoding="utf-8") as f:
    f.write("Аня,5\nБорис,4\nВика,5\n")

with open("class.csv", encoding="utf-8") as f:
    for line in f:
        name, grade = line.strip().split(",")
        print(f"{name} получил(а) {grade}")

Для сложных таблиц (например, когда внутри значений тоже бывают запятые) в Python есть готовый модуль csv — о модулях вы узнаете в уроке 12.

Есть ли файл?

Если открыть на чтение файл, которого нет, программа упадёт. Проверить заранее можно функцией os.path.exists() из модуля os:

import os

if os.path.exists("settings.txt"):
    print("Настройки найдены")
else:
    print("Файла настроек нет — создаём новый")
    with open("settings.txt", "w", encoding="utf-8") as f:
        f.write("theme=dark\n")

print(os.path.exists("settings.txt"))

Запустите пример дважды: во второй раз файл уже будет существовать. Другой способ — перехватить ошибку через try/except, этому посвящён следующий урок.

Частые ошибки новичков

Ошибаться — нормально, так учатся все программисты. Главное — научиться читать сообщение об ошибке: Python подсказывает, что не так и в какой строке.

Файла нет

Так нельзя
with open("notes.txt", encoding="utf-8") as f:
    print(f.read())
Правильно
with open("notes.txt", "w", encoding="utf-8") as f:
    f.write("Заметка\n")
with open("notes.txt", encoding="utf-8") as f:
    print(f.read())

Python скажет: FileNotFoundError: [Errno 44] No such file or directory: 'notes.txt'

Файла с таким именем нет. Проверьте имя и папку или сначала создайте файл режимом "w". На вашем компьютере номер ошибки будет другим — [Errno 2], смысл тот же.

Записываем число

Так нельзя
with open("score.txt", "w", encoding="utf-8") as f:
    f.write(100)
Правильно
with open("score.txt", "w", encoding="utf-8") as f:
    f.write(str(100))

Python скажет: TypeError: write() argument must be str, not int

write принимает только строки. Превратите число в строку: str(100).

Пишем в файл, открытый для чтения

Так нельзя
with open("a.txt", "w", encoding="utf-8") as f:
    f.write("1\n")
with open("a.txt", encoding="utf-8") as f:
    f.write("2\n")
Правильно
with open("a.txt", "w", encoding="utf-8") as f:
    f.write("1\n")
with open("a.txt", "a", encoding="utf-8") as f:
    f.write("2\n")

Python скажет: io.UnsupportedOperation: not writable

Без режима файл открывается только для чтения. Чтобы добавить строку, откройте его в режиме "a".

Читаем после закрытия

Так нельзя
with open("a.txt", "w", encoding="utf-8") as f:
    f.write("текст")
with open("a.txt", encoding="utf-8") as f:
    pass
print(f.read())
Правильно
with open("a.txt", "w", encoding="utf-8") as f:
    f.write("текст")
with open("a.txt", encoding="utf-8") as f:
    print(f.read())

Python скажет: ValueError: I/O operation on closed file.

Когда блок with закончился, файл уже закрыт. Всё чтение и запись должны быть внутри блока, с отступом.

Главное за урок

  • Файл открывают через with open(имя, режим, encoding="utf-8") as f: — после блока он закроется сам.
  • "r" — читать, "w" — записать заново (старое стирается), "a" — дописать в конец.
  • f.write(строка) не ставит перенос сам — добавляйте \n. Записывать можно только строки.
  • for line in f: читает файл по строкам; line.strip() убирает перенос в конце.
  • Числа хранятся в файле как текст: при записи — str(), при чтении — int().
