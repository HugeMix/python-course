Условия: if, elif, else

Учим программу принимать решения: «если так — делай одно, иначе — другое».

Цель урока

Научиться писать программы, которые принимают решения: проверять условия с помощью if, elif и else, сравнивать значения и объединять несколько условий через and, or и not.

Время: около 40 минут · 2 упражнения в уроке · тест · 4 задачи на дом

Зачем это нужно

Каждый день мы принимаем решения: если идёт дождь — берём зонт, иначе — нет. Если на карте хватает денег — покупка проходит, иначе — появляется сообщение «Недостаточно средств».

Программам тоже нужно принимать решения. Сайт проверяет, верный ли пароль. Игра решает, закончилась ли она, когда у героя кончились жизни. Без условий программа выполняла бы одни и те же строки одинаково, что бы ни случилось. В этом уроке вы научитесь писать программы, которые «думают» и выбирают, что делать.

Первое условие: if

Слово if по-английски значит «если». Условие пишется так:

  1. слово if;
  2. то, что проверяем, — например, temperature > 20;
  3. двоеточие в конце строки;
  4. со следующей строки — действия с отступом в 4 пробела. Они выполнятся, только если условие верно.
temperature = 25

if temperature > 20:
    print("Тепло — можно идти без куртки")

print("Программа закончилась")

Нажмите «Запустить» и посмотрите результат. Потом поменяйте 25 на 10 прямо в примере и запустите снова: первая строка исчезнет, а «Программа закончилась» останется. Она написана без отступа, поэтому не относится к условию и выполняется всегда.

Как сравнивать: операторы сравнения

Условие — это вопрос, на который есть ответ «да» (True) или «нет» (False). Чтобы задать такой вопрос, используют операторы сравнения:

ОператорЧто значитПримерОтвет
==равно5 == 5True
!=не равно5 != 3True
>больше2 > 7False
<меньше2 < 7True
>=больше или равно18 >= 18True
<=меньше или равно3 <= 1False
Главное правило: одно = — это «положить значение в переменную», а два == — это «сравнить». age = 18 записывает 18 в переменную, а age == 18 спрашивает: «age равно 18?» 
print(10 > 3)
print(10 == 3)
print("кот" == "кот")
print("Кот" == "кот")

Обратите внимание на последнюю строку: для Python «Кот» и «кот» — разные слова, потому что заглавная и строчная буквы различаются.

Иначе: else

Слово else значит «иначе». Его действия выполняются, когда условие в if оказалось ложным. У else не бывает своего условия — только двоеточие.

password = "python123"

if password == "python123":
    print("Добро пожаловать!")
else:
    print("Неверный пароль")

Попробуйте изменить пароль в первой строке и запустить снова — сработает ветка else.

Чётное или нечётное

Программа получает целое число через input(). Выведите слово чётное, если число делится на 2 без остатка, и нечётное — если нет.

Подсказка

Остаток от деления даёт оператор %: у чётного числа n % 2 == 0. Нужны if и else, и не забудьте двоеточия.

Несколько вариантов: elif

Когда вариантов больше двух, используют elif — сокращение от «else if», «иначе если». Python проверяет условия сверху вниз и выполняет только первую подходящую ветку. Остальные он даже не смотрит.

score = 78

if score >= 90:
    print("Оценка: 5")
elif score >= 70:
    print("Оценка: 4")
elif score >= 50:
    print("Оценка: 3")
else:
    print("Оценка: 2")

Число 78 больше 50, но выведется «Оценка: 4»: Python дошёл до условия score >= 70, оно оказалось верным, и на этом проверка закончилась. Поэтому порядок условий важен: если поставить score >= 50 первым, у всех от 50 до 100 будет тройка.

Несколько условий сразу: and, or, not

Иногда нужно проверить несколько вещей одновременно. Для этого есть три слова:

  • and — «и»: верно, только если верны оба условия;
  • or — «или»: верно, если верно хотя бы одно;
  • not — «не»: переворачивает ответ, True становится False.
age = 16
has_ticket = True

if age >= 12 and has_ticket:
    print("Проходите на фильм")
else:
    print("Вход запрещён")

day = "суббота"
if day == "суббота" or day == "воскресенье":
    print("Сегодня выходной!")

is_raining = False
if not is_raining:
    print("Можно гулять")

Пропуск на аттракцион

Программа получает два числа: сначала возраст, потом рост в сантиметрах (каждое на своей строке). На аттракцион пускают, если возраст не меньше 10 и рост не меньше 130. Выведите Можно или Нельзя.

Подсказка

Оба условия должны выполняться одновременно — значит, нужно and. «Не меньше 10» записывается как age >= 10.

Условие внутри условия

Внутрь if можно положить ещё один if — это называется вложенное условие. Каждый уровень добавляет ещё 4 пробела отступа.

login = "admin"
password = "12345"

if login == "admin":
    if password == "12345":
        print("Вход выполнен")
    else:
        print("Неверный пароль")
else:
    print("Пользователь не найден")

Вложенные условия удобны, когда второе действие имеет смысл только после первого (сначала нашли пользователя — потом проверяем пароль). Но больше 2–3 уровней лучше не делать: код становится трудно читать. Часто вложенность можно заменить на and или elif.

Частые ошибки новичков

Ошибаться — нормально, так учатся все программисты. Главное — научиться читать сообщение об ошибке: Python всегда подсказывает, что не так и в какой строке.

Забыли двоеточие

Так нельзя
age = 20
if age >= 18
    print("Взрослый")
Правильно
age = 20
if age >= 18:
    print("Взрослый")

Python скажет: SyntaxError: expected ':'

Python ожидал двоеточие в конце строки с if. Двоеточие нужно после if, elif и else.

Нет отступа

Так нельзя
age = 20
if age >= 18:
print("Взрослый")
Правильно
age = 20
if age >= 18:
    print("Взрослый")

Python скажет: IndentationError: expected an indented block after 'if' statement on line 2

Действия внутри условия должны быть сдвинуты на 4 пробела. Нажмите Tab или поставьте 4 пробела.

Одно «=» вместо двух

Так нельзя
age = 20
if age = 18:
    print("Ровно 18")
Правильно
age = 20
if age == 18:
    print("Ровно 18")

Python скажет: SyntaxError: invalid syntax. Maybe you meant '==' or ':=' instead of '='?

Python даже подсказывает решение: для сравнения нужно ==.

Сравнили текст с числом

Так нельзя
age = input("Сколько вам лет? ")
if age > 13:
    print("Добро пожаловать")
Правильно
age = int(input("Сколько вам лет? "))
if age > 13:
    print("Добро пожаловать")

Python скажет: TypeError: '>' not supported between instances of 'str' and 'int'

input() всегда возвращает текст, а текст нельзя сравнить с числом. Превратите ввод в число через int().

Главное за урок

  • if выполняет код, только если условие верно. В конце строки — двоеточие, внутри — отступ 4 пробела.
  • else срабатывает, когда условие ложно. Своего условия у него нет.
  • elif добавляет ещё варианты. Python проверяет сверху вниз и выполняет только первую подходящую ветку.
  • Для сравнения — ==, !=, >, <, >=, <=. Одно = — это присваивание, а не сравнение.
  • and — оба условия, or — хотя бы одно, not — наоборот.
