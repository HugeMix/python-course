Урок 4: Условные операторы (if, else, elif)

Как программа может принимать решения и выполнять разные действия в зависимости от условий.

🎯 Цель урока

Познакомиться с конструкцией if-else, научиться использовать условия в программах.

📃 Что такое условные операторы?

Иногда программа должна выполнять разные действия в зависимости от ситуации. Для этого используются условные операторы. Они позволяют задать вопрос: «Если это условие выполняется - делай одно, иначе - другое».

✅ Оператор if - простая проверка условия

Синтаксис условия if:

age = 18
if age >= 18:
    print("Вы совершеннолетний!")

Если условие age >= 18 верно (True), выполняется код внутри блока if. Важно: после условия всегда ставится двоеточие (:), а код внутри блока пишется с отступом в 4 пробела.

➖ Добавляем else - ветка «иначе»

Блок else выполняется тогда, когда условие if оказалось ложным:

age = 16
if age >= 18:
    print("Вы совершеннолетний!")
else:
    print("Вы ещё несовершеннолетний.")

В данном примере, так как age = 16, выполнится ветка else.

🔄 Проверка нескольких условий с elif

elif - сокращение от «else if» («иначе если»). Используется для проверки дополнительных условий, когда первое оказалось ложным. Можно использовать несколько elif подряд:

age = 10
if age >= 18:
    print("Вы взрослый.")
elif age >= 13:
    print("Вы подросток.")
else:
    print("Вы ребёнок.")

Python проверяет условия по очереди сверху вниз и выполняет первую подошедшую ветку.

📈 Логические операторы в условиях

Можно проверять несколько условий одновременно, используя логические операторы из прошлого урока:

temp = 25
if temp > 20 and temp < 30:
    print("Погода хорошая!")
  • and - оба условия должны быть верны.
  • or - хотя бы одно условие должно быть верно.
  • not - меняет значение на противоположное.

💡 Синтаксические правила

Запомните два обязательных правила Python для условий:

  • После if, elif или else всегда ставится двоеточие (:).
  • Код внутри блока условия обязательно пишется с одинаковым отступом - 4 пробела. Это не стиль, а требование языка: их отсутствие вызовет ошибку.

🧪 Проверка истинности значений

В Python условие может быть не только сравнением, но и просто значением. Следующие значения считаются «ложными» (False): 0, "" (пустая строка), [] (пустой список), None. Всё остальное - «истинное»: 

name = ""
if name:
    print("Имя введено:", name)
else:
    print("Имя не указано!")

🔀 Тернарный оператор

Иногда нужно выбрать одно из двух значений в зависимости от условия. Вместо полного блока if/else можно использовать тернарный оператор — условие в одну строку. Синтаксис: значение_если_истина if условие else значение_если_ложь:

# Обычная запись
age = 20
if age >= 18:
    status = "взрослый"
else:
    status = "несовершеннолетний"

# Тернарный оператор (в одну строку)
status = "взрослый" if age >= 18 else "несовершеннолетний"
print(status)  # взрослый

# Ещё примеры
score = 75
grade = "Сдал" if score >= 60 else "Не сдал"
number = -5
abs_value = number if number >= 0 else -number  # Аналог abs()

Тернарный оператор делает код короче, но не злоупотребляй им — если условие сложное, лучше написать полный if/else: читаемость важнее краткости.

🪆 Вложенные условия

Блок if может находиться внутри другого блока if — это называется вложенными условиями. Каждый уровень вложенности добавляет 4 пробела отступа:

age = 25
has_ticket = True

if age >= 18:
    if has_ticket:
        print("Добро пожаловать!")
    else:
        print("Нет билета — вход закрыт")
else:
    print("Вход только для взрослых (18+)")

# Более читаемо через and:
if age >= 18 and has_ticket:
    print("Добро пожаловать!")

Если условия независимы и можно объединить через and или or — предпочти это вложению. Глубокая вложенность делает код трудночитаемым. Хорошее правило: не более 2-3 уровней вложенности.

⚠️ Типичные ошибки в условиях

Вот самые распространённые ошибки новичков при работе с условиями. Изучи их сейчас — это сэкономит тебе часы отладки:

x = 5

# ОШИБКА 1: = вместо ==
# if x = 5:  # SyntaxError!
if x == 5:   # Правильно

# ОШИБКА 2: отсутствие двоеточия
# if x > 3   # SyntaxError!
if x > 3:    # Правильно

# ОШИБКА 3: неверный отступ
if x > 3:
    print("больше 3")
    print("эта строка внутри if")  # Оба print внутри if

# ОШИБКА 4: сравнение с None
result = None
# if result == None:  # Работает, но не по-питоновски
if result is None:    # Правильно
    print("Нет значения")

Особенно запомни ошибку 1: одиночный = — это присваивание, двойной == — это сравнение. Python не позволит написать if x = 5 и сразу выдаст SyntaxError, что помогает обнаружить ошибку быстро.
