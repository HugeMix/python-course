Урок 11: Обработка ошибок (try-except)

Научимся перехватывать ошибки в коде и правильно их обрабатывать.

🎯 Цель урока

Понять, как использовать конструкции try-except для обработки ошибок и предотвращения «краша» программы.

❓ Зачем нужна обработка ошибок?

Любая программа может столкнуться с ситуацией, которую не предусмотрел программист: пользователь ввёл текст вместо числа, файл не найден, нет подключения к сети. Без обработки ошибок программа просто «падает». Блок try-except позволяет перехватить ошибку и сообщить о ней пользователю, а не аварийно завершиться.

⚠️ Базовая конструкция try-except

Код, который может вызвать ошибку, помещается в блок try. В блоке except описывается, что делать при возникновении ошибки: 

try:
    число = int(input("Введите число: "))
    print("Вы ввели:", число)
except ValueError:
    print("Ошибка! Нужно ввести число, а не текст.")

Если пользователь введёт буквы вместо числа, возникнет ошибка ValueError, и выполнится блок except вместо «краша».

🔄 Блок finally - выполняется всегда

Блок finally выполняется всегда - и при ошибке, и при успешном выполнении. Удобен для закрытия ресурсов:

try:
    файл = open("data.txt", "r")
    содержимое = файл.read()
    print(содержимое)
except FileNotFoundError:
    print("Ошибка! Файл не найден.")
finally:
    print("Попытка чтения файла завершена.")

🚨 Типы ошибок (исключений) в Python

Популярные встроенные типы ошибок:

  • ValueError - неверное значение (например, int("abc"))
  • ZeroDivisionError - деление на ноль (10 / 0)
  • FileNotFoundError - файл не найден
  • TypeError - операция с неверным типом данных
  • Exception - базовый класс всех ошибок. Перехватывает любую ошибку. Используйте его с осторожностью. 
# Перехватить любую ошибку и вывести её описание:
try:
    result = 10 / 0
except Exception as e:
    print("Произошла ошибка:", e)

🚀 Ключевое слово raise - принудительный вызов ошибки

Иногда нужно намеренно вызвать ошибку, если данные некорректны. Для этого используется ключевое слово raise:

age = -5
if age < 0:
    raise ValueError("Возраст не может быть отрицательным!")
print("Возраст:", age)

Если выполнить этот код, программа выбросит ошибку ValueError с нашим сообщением.

🔗 Несколько блоков except

Можно обработать разные типы ошибок по-разному:

try:
    x = int(input("Введите делимое: "))
    y = int(input("Введите делитель: "))
    print("Результат:", x / y)
except ValueError:
    print("Введите только числа!")
except ZeroDivisionError:
    print("На ноль делить нельзя!")

🔢 Основные виды исключений

В Python существует множество встроенных исключений. Знание наиболее частых поможет быстро находить причину ошибки и писать более надёжный код:

# TypeError — несовместимые типы
try:
    result = "5" + 5
except TypeError as e:
    print(f"TypeError: {e}")

# ValueError — неверное значение
try:
    number = int("привет")
except ValueError as e:
    print(f"ValueError: {e}")

# IndexError — выход за границы
try:
    lst = [1, 2, 3]
    print(lst[10])
except IndexError as e:
    print(f"IndexError: {e}")

# KeyError — ключ не найден в словаре
try:
    d = {"a": 1}
    print(d["z"])
except KeyError as e:
    print(f"KeyError: {e}")

🛡️ else и finally в связке с try-except

Блок else выполняется только если в блоке try не возникло ни одной ошибки — это удобно для кода, который должен работать исключительно при успехе. Блок finally выполняется в любом случае:

def safe_divide(a, b):
    try:
        result = a / b
    except ZeroDivisionError:
        print("Ошибка: деление на ноль!")
        return None
    except TypeError:
        print("Ошибка: передайте числа, не строки!")
        return None
    else:
        # Выполняется только если НЕ было ошибки
        print("Деление выполнено успешно")
        return result
    finally:
        # Выполняется ВСЕГДА
        print("Функция завершена")

print(safe_divide(10, 2))    # 5.0
print(safe_divide(10, 0))    # None
print(safe_divide("10", 2))  # None

🏗️ Создание своего исключения

Когда встроенных исключений недостаточно для описания бизнес-логики, можно создать собственный класс исключения, унаследовав его от Exception:

# Свои исключения для бизнес-логики
class AgeError(Exception):
    """Исключение для неверного возраста"""
    pass

class NegativeValueError(Exception):
    def __init__(self, value):
        self.value = value
        super().__init__(f"Значение не может быть отрицательным: {value}")

def set_age(age):
    if not isinstance(age, int):
        raise TypeError("Возраст должен быть целым числом")
    if age < 0 or age > 150:
        raise AgeError(f"Невозможный возраст: {age}")
    return age

try:
    set_age(-5)
except AgeError as e:
    print(f"Ошибка: {e}")

🔒 Практический пример: надёжный ввод

Объединим обработку исключений с циклом, чтобы программа продолжала просить ввод до тех пор, пока пользователь не введёт корректное значение:

def get_positive_number(prompt):
    """Запрашивает положительное число до тех пор пока не введут верное"""
    while True:
        try:
            value = float(input(prompt))
            if value <= 0:
                raise ValueError("Число должно быть положительным")
            return value
        except ValueError as e:
            print(f"Неверный ввод: {e}. Попробуй снова.")

# Использование
price = get_positive_number("Введи цену товара: ")
quantity = get_positive_number("Введи количество: ")
print(f"Итого: {price * quantity:.2f} руб.")
