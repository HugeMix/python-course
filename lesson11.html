Обработка ошибок: try и except

Учим программу не падать, а вежливо сообщать о проблеме.

Цель урока

Научиться читать сообщения об ошибках, перехватывать их с помощью try и except, использовать else и finally, повторять ввод до правильного значения и вызывать ошибки самостоятельно через raise.

Время: около 45 минут · 2 упражнения в уроке · тест · 4 задачи на дом

Зачем это нужно

Программы работают с реальным миром, а он непредсказуем. Пользователь вместо возраста введёт «двадцать», файл удалят, интернет пропадёт, в делителе окажется ноль. До сих пор при любой такой ошибке программа просто падала с красным сообщением.

Хорошая программа так себя не ведёт: она замечает проблему, вежливо объясняет её и продолжает работать. В этом уроке вы научитесь перехватывать ошибки с помощью try и except.

Как выглядит ошибка

Ошибки в Python называются исключениями. У каждой есть тип и описание. Запустите пример — программа упадёт на второй строке, и третья уже не выполнится:

age = int("двадцать")
print("Эта строка не выполнится")

Последняя строка сообщения — самая важная: ValueError — тип ошибки, после двоеточия — объяснение. Вот типы, которые встречаются чаще всего:

ТипКогда возникаетПример
ValueErrorзначение не подходитint("abc")
TypeErrorдействие с неподходящим типом"5" + 5
ZeroDivisionErrorделение на ноль10 / 0
IndexErrorнет элемента с таким индексом[1, 2][5]
KeyErrorнет такого ключа в словаре{}["x"]

Перехватываем ошибку: try и except

Код, который может упасть, кладут в блок try («попробуй»). Если в нём случилась ошибка, Python не останавливает программу, а переходит в блок except («кроме случая, когда…»):

text = input("Введите возраст: ")

try:
    age = int(text)
    print("Через год вам будет", age + 1)
except ValueError:
    print("Это не число. Введите возраст цифрами")

print("Программа продолжает работать")

Поменяйте ввод на число в коде (например, замените input(...) на "15") и запустите снова: ошибки не будет, и блок except пропустится.

Указывайте тип ошибки. except ValueError: ловит только ошибки преобразования. Если написать просто except:, программа будет молча глотать любые ошибки — даже опечатки в вашем коде, и найти их станет очень трудно.

Надёжное деление

Программа получает два значения, каждое на своей строке, и делит первое на второе. Если всё хорошо — выведите результат. Если ввели не число — выведите Это не число, если делитель ноль — На ноль делить нельзя.

Подсказка

Внутри try: print(int(a) / int(b)). После него два блока: except ValueError: и except ZeroDivisionError:.

Несколько except и текст ошибки

Как в упражнении выше, блоков except может быть несколько — для разных ошибок. А записью except ... as e можно получить саму ошибку и, например, показать её описание:

data = ["10", "0", "abc"]

for item in data:
    try:
        print(100 / int(item))
    except ZeroDivisionError:
        print("Деление на ноль пропущено")
    except ValueError as e:
        print("Неверные данные:", e)

else и finally

У try есть ещё два необязательных блока:

  • else — выполняется, если ошибки не было;
  • finally — выполняется всегда, была ошибка или нет. Сюда пишут то, что нужно сделать в любом случае: закрыть соединение, сохранить данные, вывести «готово».
for text in ["42", "сорок два"]:
    try:
        n = int(text)
    except ValueError:
        print(text, "→ ошибка")
    else:
        print(text, "→ число", n)
    finally:
        print("проверка завершена")

Повторяем ввод, пока он не станет правильным

Самый полезный приём этого урока: соединить while True, try и break. Программа спрашивает снова и снова, пока не получит нормальное число:

while True:
    try:
        age = int(input("Сколько вам лет? "))
        break
    except ValueError:
        print("Нужно ввести число цифрами")

print("Принято, вам", age)

Если int() упал, до break дело не доходит — срабатывает except, и цикл повторяется. Если число получилось — break выходит из цикла.

Подсказка

Внутри цикла: try: n = int(text), в except ValueError: напечатайте сообщение и сделайте continue. После этого проверьте диапазон: if 1 <= n <= 10: — печать и break, иначе — сообщение.

Вызываем ошибку сами: raise

Иногда ошибку нужно создать самому. Например, функция получила отрицательный возраст: Python не видит в этом ничего плохого, а для вашей программы это ошибка. Словом raise можно «выбросить» исключение с понятным описанием:

def set_age(age):
    if age < 0 or age > 120:
        raise ValueError("Возраст должен быть от 0 до 120")
    return age

print(set_age(30))

try:
    set_age(-5)
except ValueError as e:
    print("Ошибка:", e)

Так функции сообщают тому, кто их вызвал, что данные неправильные. А тот уже решает, что делать: показать сообщение, спросить заново или записать в журнал.

Частые ошибки новичков

Ошибаться — нормально, так учатся все программисты. Главное — научиться читать сообщение об ошибке: Python подсказывает, что не так и в какой строке.

Ловим не ту ошибку

Так нельзя
try:
    n = int("abc")
except ZeroDivisionError:
    print("Ошибка")
Правильно
try:
    n = int("abc")
except ValueError:
    print("Ошибка")

Python скажет: ValueError: invalid literal for int() with base 10: 'abc'

except ловит только указанный тип. Здесь возникла ValueError, а ловили ZeroDivisionError — ошибка прошла мимо и программа упала.

try без except

Так нельзя
try:
    n = int("5")
print(n)
Правильно
try:
    n = int("5")
except ValueError:
    n = 0
print(n)

Python скажет: SyntaxError: expected 'except' or 'finally' block

После блока try обязательно должен идти except или finally.

raise со строкой

Так нельзя
raise "Неверный возраст"
Правильно
try:
    raise ValueError("Неверный возраст")
except ValueError as e:
    print(e)

Python скажет: TypeError: exceptions must derive from BaseException

Выбросить можно только исключение, а не просто строку. Создайте исключение нужного типа и передайте текст в скобках.

Главное за урок

  • Ошибки в Python — исключения: ValueError, TypeError, ZeroDivisionError, KeyError и другие. Главное — последняя строка сообщения.
  • try: — код, который может упасть; except Тип: — что делать при этой ошибке.
  • Указывайте конкретный тип ошибки. except ValueError as e даёт доступ к описанию ошибки.
  • else — если ошибки не было, finally — выполняется всегда.
  • while True + try + break — повторять ввод, пока он не станет правильным. raise вызывает ошибку самостоятельно.
