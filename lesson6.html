Списки и кортежи

Храним много значений в одной переменной: оценки, покупки, имена.

Цель урока

Научиться хранить много значений в одном списке, обращаться к элементам по индексу, добавлять и удалять элементы, перебирать список циклом, брать срезы и понять, чем кортеж отличается от списка.

Время: около 45 минут · 2 упражнения в уроке · тест · 4 задачи на дом

Зачем это нужно

Одна переменная хранит одно значение. А если нужно запомнить оценки всего класса, список покупок или рекорды игроков? Заводить переменные grade1, grade2, … grade30 неудобно — и непонятно, что делать, если учеников станет 31.

Для этого есть списки: одна переменная, в которой лежит сколько угодно значений по порядку. Плейлист, лента новостей, корзина в магазине, таблица рекордов — всё это списки.

Создаём список

Список пишут в квадратных скобках, значения разделяют запятыми:

fruits = ["яблоко", "банан", "груша"]
grades = [5, 4, 5, 3]
empty = []

print(fruits)
print(grades)
print("Сколько фруктов:", len(fruits))
print("Пустой список:", empty, "длина", len(empty))

Команда len() возвращает длину — количество элементов в списке.

Номер элемента — индекс

Каждый элемент списка стоит на своём месте, и у места есть номер — индекс. Главная особенность: нумерация начинается с нуля.

Индекс0123
Элемент"Аня""Борис""Вика""Гоша"
Индекс с конца-4-3-2-1
 
names = ["Аня", "Борис", "Вика", "Гоша"]

print(names[0])
print(names[2])
print(names[-1])

names[1] = "Богдан"
print(names)

Отрицательный индекс считает с конца: names[-1] — последний элемент, удобно, когда длина списка неизвестна. Элемент можно заменить: names[1] = "Богдан".

Добавляем и удаляем

У списка есть встроенные команды — методы. Их пишут через точку после имени списка:

МетодЧто делает
lst.append(x)добавить x в конец
lst.insert(i, x)вставить x на место с индексом i
lst.remove(x)удалить первый элемент, равный x
lst.pop()убрать последний элемент и вернуть его
lst.sort()отсортировать список по возрастанию
 
cart = ["хлеб", "молоко"]

cart.append("сыр")
print(cart)

cart.insert(0, "яйца")
print(cart)

cart.remove("молоко")
print(cart)

last = cart.pop()
print("Убрали:", last, "- осталось:", cart)

Перебираем список циклом

Цикл for проходит по списку и по очереди кладёт каждый элемент в переменную цикла — так же, как вы перебирали буквы строки в уроке 5:

grades = [5, 4, 3, 5, 4]

for g in grades:
    print("Оценка:", g)

print("Сумма:", sum(grades))
print("Лучшая:", max(grades), "худшая:", min(grades))
print("Средняя:", sum(grades) / len(grades))

Для чисел есть готовые команды: sum() — сумма, max() и min() — наибольшее и наименьшее. Проверить, есть ли значение в списке, можно словом in: "сыр" in cart даёт True или False.

Собираем список из ввода

Частая задача: прочитать несколько значений и сложить их в список. Начинают с пустого списка и в цикле добавляют элементы через append:

n = int(input())
numbers = []
for i in range(n):
    numbers.append(int(input()))

print("Список:", numbers)
print("Сумма:", sum(numbers))

Сначала программа читает N — сколько будет чисел, потом N раз читает по числу. Если же все значения пришли в одной строке через пробел, их разрезают командой split(): input().split() превращает строку «3 7 1» в список ["3", "7", "1"].

Первый и последний

Программа получает число N, а потом N слов, каждое на своей строке. Выведите первое и последнее слово через пробел.

Подсказка

Слова складывайте через words.append(input()) в цикле for. Первое слово — words[0], последнее — words[-1].

Срезы: часть списка

Можно взять не один элемент, а кусок списка — срез. Записывается lst[начало:конец], и, как в range, конец не включается:

nums = [10, 20, 30, 40, 50, 60]

print(nums[1:4])
print(nums[:3])
print(nums[3:])
print(nums[::-1])

nums[:3] — первые три, nums[3:] — всё начиная с индекса 3, а nums[::-1] — весь список задом наперёд. Срезы работают и со строками: "Python"[:3] — это "Pyt".

Только чётные

Программа получает число N, а потом N целых чисел, каждое на своей строке. Выведите в одну строку через пробел только чётные числа, в том же порядке.

Подсказка

Соберите чётные числа в список evens (проверка x % 2 == 0). Вывести в строку можно циклом с print(x, end=" ").

Кортежи: список, который нельзя менять

Кортеж (tuple) похож на список, но пишется в круглых скобках и после создания не меняется: в него нельзя ничего добавить, удалить или заменить. Кортежи используют для данных, которые не должны случайно измениться: координаты точки, дни недели, цвет в формате RGB.

point = (3, 7)
days = ("пн", "вт", "ср", "чт", "пт", "сб", "вс")

print("x =", point[0], "y =", point[1])
print("Рабочих дней:", len(days[:5]))

x, y = point
print(x + y)

Последние строки показывают распаковку: x, y = point раскладывает кортеж по двум переменным.

Генератор списка

Когда новый список получают из старого, можно записать это в одну строку. Это называется генератор списка (list comprehension) — не обязательно использовать его сразу, но в чужом коде он встречается постоянно:

nums = [1, 2, 3, 4, 5, 6]

squares = [x ** 2 for x in nums]
evens = [x for x in nums if x % 2 == 0]

print(squares)
print(evens)

Читается почти как фраза: «x ** 2 для каждого x из nums», «x для каждого x из nums, если x чётный».

Частые ошибки новичков

Ошибаться — нормально, так учатся все программисты. Главное — научиться читать сообщение об ошибке: Python подсказывает, что не так и в какой строке.

Индекс за пределами списка

Так нельзя
colors = ["красный", "зелёный", "синий"]
print(colors[3])
Правильно
colors = ["красный", "зелёный", "синий"]
print(colors[2])

Python скажет: IndexError: list index out of range

В списке из трёх элементов индексы 0, 1 и 2. Индекса 3 нет. Последний элемент надёжнее брать как colors[-1].

Удаляем то, чего нет

Так нельзя
cart = ["хлеб", "сыр"]
cart.remove("молоко")
Правильно
cart = ["хлеб", "сыр"]
if "молоко" in cart:
    cart.remove("молоко")
print(cart)

Python скажет: ValueError: list.remove(x): x not in list

remove падает, если такого элемента нет. Проверьте заранее через in.

Добавляем два элемента сразу

Так нельзя
nums = [1, 2]
nums.append(3, 4)
Правильно
nums = [1, 2]
nums.append(3)
nums.append(4)
print(nums)

Python скажет: TypeError: list.append() takes exactly one argument (2 given)

append добавляет ровно один элемент. Вызовите его дважды или используйте extend со списком.

Меняем кортеж

Так нельзя
point = (3, 7)
point[0] = 5
Правильно
point = (3, 7)
point = (5, point[1])
print(point)

Python скажет: TypeError: 'tuple' object does not support item assignment

Кортеж менять нельзя. Если данные должны меняться — используйте список в квадратных скобках или создайте новый кортеж.

Главное за урок

  • Список хранит много значений по порядку: [5, 4, 3]. Длина — len(lst).
  • Индексы начинаются с 0, lst[-1] — последний элемент. Срез lst[1:4] — часть списка, конец не включается.
  • append — добавить в конец, insert — вставить, remove и pop — удалить, sort — отсортировать.
  • for x in lst: перебирает элементы. Для чисел есть sum, min, max, а проверка наличия — x in lst.
  • Кортеж (3, 7) — как список, только неизменяемый.
