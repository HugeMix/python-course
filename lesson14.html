Дата и время

Считаем дни до каникул, возраст и дни недели с модулем datetime.

Цель урока

Научиться работать с датами и временем: получать текущую дату, создавать свои даты, выводить их в нужном формате и читать из строки, прибавлять дни и находить разницу между датами, считать полные годы.

Время: около 45 минут · 2 упражнения в уроке · тест · 4 задачи на дом

Зачем это нужно

Даты и время нужны почти везде: сколько дней осталось до каникул или отпуска, когда истекает подписка, во сколько напомнить о встрече, сколько полных лет человеку, какой день недели будет 1 сентября. Считать это вручную неудобно: в месяцах разное число дней, бывают високосные годы.

В Python для этого есть модуль datetime. Он сам знает календарь и умеет складывать, вычитать и сравнивать даты.

Сегодняшняя дата и текущее время

Из модуля datetime чаще всего подключают два класса: date — только дата и datetime — дата вместе со временем.

from datetime import date, datetime

today = date.today()
now = datetime.now()

print("Сегодня:", today)
print("Сейчас:", now)
print("Год:", today.year, "месяц:", today.month, "день:", today.day)
print("Время:", now.hour, "ч", now.minute, "мин")

У даты есть атрибуты year, month, day, а у даты со временем ещё hour, minute, second. По умолчанию дата выводится в формате ГГГГ-ММ-ДД — это международный стандарт.

Своя дата

Конкретную дату создают, передавая год, месяц и день:

from datetime import date

new_year = date(2027, 1, 1)
birthday = date(2012, 5, 17)

print(new_year)
print("Номер дня недели:", new_year.weekday())

days = ["понедельник", "вторник", "среда", "четверг", "пятница", "суббота", "воскресенье"]
print("1 января 2027 —", days[new_year.weekday()])

Метод weekday() возвращает номер дня недели: 0 — понедельник, 6 — воскресенье. Чтобы получить название по-русски, удобно взять его из списка по этому номеру.

Красивый формат: strftime

Чтобы вывести дату в привычном виде, используют метод strftime (string format time). В строке-шаблоне специальные коды заменяются частями даты:

КодЧто подставитсяПример
%dдень, две цифры05
%mмесяц, две цифры09
%Yгод, четыре цифры2026
%Hчасы (00–23)14
%Mминуты07
%Sсекунды30
 
from datetime import datetime

moment = datetime(2026, 9, 1, 8, 30)

print(moment.strftime("%d.%m.%Y"))
print(moment.strftime("%H:%M"))
print(moment.strftime("Дата: %d.%m.%Y, время: %H:%M"))

Названия месяцев strftime выдаёт по-английски, поэтому для русских удобнее свой список: months[d.month - 1].

Из строки в дату: strptime

Обратная задача: пользователь ввёл дату текстом, а программе нужна настоящая дата, чтобы с ней считать. Для этого есть datetime.strptime (string parse time) — ему передают строку и шаблон, по которому её читать:

from datetime import datetime

text = "17.05.2012"
d = datetime.strptime(text, "%d.%m.%Y").date()

print(d)
print("Год рождения:", d.year)

strptime возвращает дату со временем, а .date() оставляет только дату. Шаблон должен точно совпадать с текстом: точки, дефисы и порядок чисел.

Арифметика дат: timedelta

timedelta — это промежуток времени: столько-то дней, часов, минут. Его можно прибавлять к датам и вычитать. А если вычесть одну дату из другой, получится как раз timedelta — у него есть атрибут days:

from datetime import date, timedelta

start = date(2026, 11, 11)

print("Через неделю:", start + timedelta(days=7))
print("Через 100 дней:", start + timedelta(days=100))
print("Вчера:", start - timedelta(days=1))

summer = date(2027, 6, 1)
left = summer - start
print("До лета дней:", left.days)

Python сам учитывает, сколько дней в каждом месяце и високосные годы. Даты можно и сравнивать: date(2027, 1, 1) > date(2026, 12, 31) — это True.

Подсказка

result = start + timedelta(days=n), а потом print(result.strftime("%d.%m.%Y")).

Сколько полных лет

Частая задача — посчитать возраст. Просто вычесть годы мало: если день рождения в этом году ещё не наступил, нужно отнять единицу. Сравнить «наступил ли день рождения» удобно кортежами (месяц, день) — они сравниваются по порядку, как слова в словаре:

from datetime import date

def full_years(birth, today):
    years = today.year - birth.year
    if (today.month, today.day) < (birth.month, birth.day):
        years -= 1
    return years

birth = date(2012, 5, 17)
print(full_years(birth, date(2026, 5, 16)))
print(full_years(birth, date(2026, 5, 17)))

Подсказка

days = (event - today).days. Дальше — условие: больше нуля, равно нулю или меньше.

Время в секундах и паузы: модуль time

Модуль time пригодится, чтобы замерить, сколько работает код, или сделать паузу. time.time() возвращает количество секунд, прошедших с 1 января 1970 года — так компьютеры хранят моменты времени. Разница двух таких чисел — сколько секунд прошло:

import time

start = time.time()
total = 0
for i in range(1_000_000):
    total += i
finish = time.time()

print("Сумма:", total)
print("Заняло секунд:", round(finish - start, 3))

time.sleep(2) останавливает программу на 2 секунды — так делают, например, обратный отсчёт в играх. Подчёркивания в 1_000_000 — просто для удобства чтения, Python их не замечает.

Частые ошибки новичков

Ошибаться — нормально, так учатся все программисты. Главное — научиться читать сообщение об ошибке: Python подсказывает, что не так и в какой строке.

Перепутали модуль и класс

Так нельзя
import datetime
print(datetime.now())
Правильно
from datetime import datetime
print(datetime.now())

Python скажет: AttributeError: module 'datetime' has no attribute 'now'

Модуль и класс внутри него называются одинаково — datetime. После import datetime нужно писать datetime.datetime.now(). Проще подключать класс напрямую.

Шаблон не совпадает с текстом

Так нельзя
from datetime import datetime
d = datetime.strptime("11.11.2026", "%Y-%m-%d")
Правильно
from datetime import datetime
d = datetime.strptime("11.11.2026", "%d.%m.%Y")
print(d.date())

Python скажет: ValueError: time data '11.11.2026' does not match format '%Y-%m-%d'

Шаблон ждал год через дефисы, а пришла дата через точки. Шаблон должен повторять текст символ в символ.

Несуществующая дата

Так нельзя
from datetime import date
d = date(2026, 2, 30)
Правильно
from datetime import date
d = date(2026, 2, 28)
print(d)

Python скажет: ValueError: day is out of range for month

30 февраля не бывает. Python проверяет каждую дату по календарю.

Прибавили к дате число

Так нельзя
from datetime import date
print(date(2026, 1, 1) + 1)
Правильно
from datetime import date, timedelta
print(date(2026, 1, 1) + timedelta(days=1))

Python скажет: TypeError: unsupported operand type(s) for +: 'datetime.date' and 'int'

Непонятно, чего добавить — дней, часов или лет. Промежуток задаётся через timedelta.

Главное за урок

  • from datetime import date, datetime, timedelta — всё нужное для дат. date.today() — сегодня, datetime.now() — сейчас.
  • date(2027, 1, 1) создаёт дату; у неё есть year, month, day и weekday() (0 — понедельник).
  • strftime("%d.%m.%Y") — дата в строку, datetime.strptime(текст, шаблон) — строка в дату.
  • timedelta(days=7) прибавляют и вычитают. Разность дат — промежуток, количество дней — .days.
  • time.time() — секунды с 1970 года, удобно замерять время работы. time.sleep(n) — пауза.
