Урок 14: Работа с датой и временем

Изучаем модуль datetime и способы форматирования даты и времени.

🎯 Цель урока

Познакомиться с модулем datetime и научиться получать, форматировать и вычислять разницу между датами.

📅 Модуль datetime

Python предоставляет встроенный модуль datetime для работы с датами и временем. Чтобы использовать его, нужно импортировать класс datetime из одноимённого модуля:

from datetime import datetime

now = datetime.now()
print("Текущая дата и время:", now)

⏳ Форматирование даты - метод strftime()

Метод strftime() конвертирует объект даты в строку по заданному шаблону. Название: string format time:

from datetime import datetime

now = datetime.now()
formatted_date = now.strftime("%d.%m.%Y %H:%M:%S")
print("Отформатированная дата:", formatted_date)
# Пример вывода: 02.03.2025 19:21:14

Основные символы форматирования:

  • %Y - год (четыре цифры, например 2025)
  • %m - месяц (01–12)
  • %d - день (01–31)
  • %H - час (00–23)
  • %M - минуты (00–59)
  • %S - секунды (00–59)

📆 Создание своей даты

Объект даты можно создать вручную, передав год, месяц, день и (опционально) время:

from datetime import datetime

custom_date = datetime(2025, 5, 17, 15, 30)
print("Созданная дата:", custom_date)
# Выведет: 2025-05-17 15:30:00

⏱️ Разница во времени - timedelta

Если вычесть одну дату из другой, получится объект timedelta - он хранит разницу в днях и секундах:

from datetime import datetime, timedelta

now = datetime.now()
deadline = datetime(2025, 12, 31)
delta = deadline - now
print("До конца года осталось:", delta.days, "дней")

С помощью timedelta можно также прибавлять или вычитать дни из даты:

from datetime import datetime, timedelta

today = datetime.now()
next_week = today + timedelta(days=7)
print("Через неделю будет:", next_week.strftime("%d.%m.%Y"))

🔄 Парсинг строки в дату (strptime)

Метод strptime() делает обратное по отношению к strftime(): он превращает строку в объект datetime. Название: string parse time.

from datetime import datetime

# strptime — строка → объект datetime
date_str = "25.12.2024"
date = datetime.strptime(date_str, "%d.%m.%Y")
print(date)             # 2024-12-25 00:00:00
print(type(date))       # <class 'datetime.datetime'>

# Различные форматы
date1 = datetime.strptime("2024-03-15", "%Y-%m-%d")
date3 = datetime.strptime("25/12/2024 14:30", "%d/%m/%Y %H:%M")

# Удобный паттерн: конвертация между форматами
input_date = "2024-12-25"
date_obj = datetime.strptime(input_date, "%Y-%m-%d")
output_date = date_obj.strftime("%d.%m.%Y")
print(output_date)  # 25.12.2024

⏱️ Практические вычисления с датами

Комбинируя strptime, datetime.now() и timedelta, можно решать реальные задачи: считать возраст, вычислять дедлайны и дни до события.

from datetime import datetime, timedelta

# Калькулятор возраста
def calculate_age(birth_date_str):
    birth = datetime.strptime(birth_date_str, "%d.%m.%Y")
    today = datetime.now()
    age = today.year - birth.year
    # Проверяем был ли день рождения в этом году
    if (today.month, today.day) < (birth.month, birth.day):
        age -= 1
    return age

age = calculate_age("15.08.1995")
print(f"Возраст: {age} лет")

# Дедлайн через N дней
deadline = datetime.now() + timedelta(days=30)
print(f"Дедлайн: {deadline.strftime('%d.%m.%Y')}")

# Сколько дней до Нового года
today = datetime.now()
new_year = datetime(today.year + 1, 1, 1)
days_left = (new_year - today).days
print(f"До Нового года осталось {days_left} дней")

🌍 Unix timestamp

Unix timestamp — это количество секунд, прошедших с 1 января 1970 года (эпохи Unix). Широко используется в логах, базах данных и API-ответах, потому что не зависит от часового пояса.

from datetime import datetime

# Unix timestamp — количество секунд с 1 января 1970 года
import time
timestamp = time.time()
print(f"Timestamp: {timestamp}")  # Например: 1703500800.123

# Преобразование timestamp в datetime
dt = datetime.fromtimestamp(timestamp)
print(dt.strftime("%d.%m.%Y %H:%M:%S"))

# Datetime → timestamp
dt = datetime(2024, 1, 1, 0, 0, 0)
ts = dt.timestamp()
print(ts)  # 1704056400.0

# Полезно для сравнения дат, логов, API-ответов
