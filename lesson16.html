Урок 16: Работа с API Бонус

Научимся получать данные из интернета с помощью библиотеки requests.

🎯 Цель урока

Понять что такое API, научиться делать HTTP-запросы и обрабатывать JSON-ответы с помощью библиотеки requests.

🌐 Что такое API?

API (Application Programming Interface) — это способ, которым программы разговаривают друг с другом. Представь: ты в ресторане. Ты (программа) говоришь официанту (API) что хочешь, официант передаёт заказ на кухню (сервер) и приносит тебе результат.

Примеры API которые ты можешь использовать прямо сейчас:

  • Погода: OpenWeatherMap — запросил название города, получил температуру
  • Случайный факт: запросил URL, получил интересный факт о числе
  • Курс валют: запросил API Центробанка, получил актуальный курс
  • Telegram Bot API: отправляешь запросы — бот пишет сообщения пользователям

📦 Библиотека requests

Python не умеет делать HTTP-запросы из коробки (стандартная библиотека urllib слишком сложная). Поэтому все используют requests — самую популярную Python-библиотеку в мире.

Установка:

pip install requests

Подключение в коде:

import requests

🚀 Первый GET-запрос

GET-запрос — это запрос на получение данных. Как когда вы открываете сайт в браузере.

import requests

response = requests.get("https://numbersapi.com/42/math")

print(response.status_code)  # 200 — значит успешно
print(response.text)         # Текст ответа

Объект response содержит всё что вернул сервер:

  • response.status_code — код статуса (200 = OK, 404 = не найдено, 500 = ошибка сервера)
  • response.text — ответ в виде строки
  • response.json() — ответ в виде Python-словаря (если сервер вернул JSON)
  • response.headers — заголовки ответа

📋 Работа с JSON-ответом

Большинство современных API возвращают данные в формате JSON — это тот же Python-словарь, только записанный в виде текста. Метод .json() автоматически превращает его в нормальный словарь.

import requests

response = requests.get("https://api.coindesk.com/v1/bpi/currentprice.json")

if response.status_code == 200:
    data = response.json()
    price = data["bpi"]["USD"]["rate"]
    print(f"Цена Bitcoin: {price} USD")
else:
    print(f"Ошибка: {response.status_code}")

🔍 Параметры запроса

Часто API принимает параметры — например название города для погоды. Их передают через аргумент params:

import requests

params = {
    "q": "Moscow",
    "appid": "ВАШ_КЛЮЧ_API",
    "units": "metric",
    "lang": "ru"
}

response = requests.get("https://api.openweathermap.org/data/2.5/weather", params=params)
data = response.json()

if response.status_code == 200:
    temp = data["main"]["temp"]
    desc = data["weather"][0]["description"]
    print(f"Москва: {temp}°C, {desc}")

⚠️ Обработка ошибок при запросах

Интернет ненадёжен. Сервер может быть недоступен, URL неправильным, или сеть пропасть. Всегда оборачивайте запросы в try-except:

import requests

try:
    response = requests.get("https://api.example.com/data", timeout=5)
    response.raise_for_status()  # Вызывает ошибку если status_code >= 400
    data = response.json()
    print(data)

except requests.exceptions.ConnectionError:
    print("Нет интернет-соединения")
except requests.exceptions.Timeout:
    print("Сервер не ответил вовремя")
except requests.exceptions.HTTPError as e:
    print(f"Ошибка HTTP: {e}")
except Exception as e:
    print(f"Неожиданная ошибка: {e}")

Аргумент timeout=5 означает: если сервер не ответил за 5 секунд — выбрасывается исключение. Без таймаута программа может висеть вечно.

📬 POST-запросы

POST используется для отправки данных на сервер (создание аккаунта, отправка сообщения, публикация поста):

import requests

data = {
    "title": "Мой первый пост",
    "body": "Привет, мир!",
    "userId": 1
}

response = requests.post("https://jsonplaceholder.typicode.com/posts", json=data)
print(response.status_code)  # 201 — создано
print(response.json())       # Созданный объект с id

💡 Практический пример: получаем случайный факт

import requests

def get_random_joke():
    """Получает случайный анекдот из бесплатного API"""
    try:
        response = requests.get(
            "https://official-joke-api.appspot.com/random_joke",
            timeout=5
        )
        if response.status_code == 200:
            joke = response.json()
            print(f"Setup: {joke['setup']}")
            print(f"Punchline: {joke['punchline']}")
        else:
            print("Не удалось получить анекдот")
    except requests.exceptions.RequestException as e:
        print(f"Ошибка сети: {e}")

get_random_joke()
