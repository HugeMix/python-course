Работа с API Бонус

Получаем данные из интернета: запросы, ответы и формат JSON.

Цель урока

Понять, как программы обмениваются данными через интернет, научиться разбирать ответы в формате JSON, узнать, как отправлять запросы библиотекой requests, передавать параметры, обрабатывать ошибки и бережно обращаться с ключами API.

Время: около 50 минут · 2 упражнения в уроке · тест · 3 задачи на дом

Зачем это нужно

Прогноз погоды в телефоне, курс валют в банковском приложении, карта в такси, кнопка «Войти через Google» — всё это данные, которые одна программа получает от другой через интернет. Способ, которым программы общаются между собой, называется API (application programming interface — «интерфейс для программ»).

API похож на официанта в кафе. Вы не идёте на кухню сами: вы делаете заказ официанту, он передаёт его на кухню и приносит готовое блюдо. Так и ваша программа отправляет запрос на сервер и получает ответ с данными. В этом уроке вы узнаете, как это устроено и как сделать это на Python.

Где запускать код этого урока. Запросы в интернет делает библиотека requests, а она не работает в примерах на этой странице. Поэтому примеры с requests показаны без кнопки «Запустить» — их нужно запускать на своём компьютере. А вот разбирать полученные данные можно прямо здесь: этому посвящена большая часть урока.

Запрос и ответ

Запрос отправляется по адресу — URL, такому же, как адрес сайта. Сервер присылает ответ, в котором есть:

  • код статуса — число, которое коротко говорит, всё ли хорошо;
  • данные — обычно в формате JSON.
КодЧто значит
200всё хорошо, данные в ответе
201создано (например, после отправки формы)
400ошибка в запросе — что-то не так с параметрами
401 / 403нет доступа: нужен ключ или нет прав
404не найдено — неверный адрес
429слишком много запросов, нужно подождать
500ошибка на стороне сервера

Запомнить просто: коды на 2 — успех, на 4 — ошибка с вашей стороны, на 5 — проблема у сервера.

Формат JSON

Почти все API присылают данные в формате JSON. Он очень похож на словари и списки Python: фигурные скобки, ключи в кавычках, значения через двоеточие. Отличия небольшие: строки только в двойных кавычках, а вместо True, False, None пишут true, false, null.

В Python для JSON есть модуль json. json.loads() превращает текст в формате JSON в словари и списки, а json.dumps() — обратно в текст:

import json

answer = '{"city": "Москва", "temp": -3, "sunny": false, "days": [1, 2, 3]}'

data = json.loads(answer)
print(type(data))
print(data["city"], data["temp"])
print("Солнечно:", data["sunny"])

back = json.dumps({"name": "Аня", "score": 120}, ensure_ascii=False)
print(back)

После json.loads с данными работают как с обычным словарём. ensure_ascii=False нужен, чтобы русские буквы в тексте JSON остались буквами, а не превратились в коды вида \u0410.

Первый запрос: requests.get

Библиотеку requests сначала устанавливают (урок 12):

pip install requests

Вот полноценный запрос к бесплатному API с тестовыми данными, которое не требует регистрации:

import requests

response = requests.get("https://jsonplaceholder.typicode.com/todos/1", timeout=10)

print(response.status_code)   # 200
data = response.json()        # сразу превращает JSON в словарь
print(data["title"])
print("Выполнено:", data["completed"])
  1. requests.get(адрес) отправляет запрос GET — «дай мне данные».
  2. timeout=10 — ждать ответа не дольше 10 секунд. Без него программа может зависнуть, если сервер не отвечает.
  3. response.status_code — код статуса.
  4. response.json() — то же, что json.loads(response.text): данные ответа в виде словаря или списка.

Параметры запроса

Часто в запросе нужно уточнить, что именно нужно: какой город, сколько записей, на каком языке. Для этого к адресу добавляют параметры: после знака ? пары ключ=значение, разделённые &. Например: …/forecast?latitude=55.75&longitude=37.62.

Собирать такой адрес вручную не нужно — requests сделает это сам, если передать словарь в params. Как получается адрес, можно посмотреть прямо здесь с помощью стандартного модуля urllib:

from urllib.parse import urlencode

params = {"latitude": 55.75, "longitude": 37.62, "current_weather": "true"}
url = "https://api.open-meteo.com/v1/forecast?" + urlencode(params)
print(url)

print(urlencode({"q": "котики", "page": 2}))

Русские буквы и пробелы в адресе кодируются специальными символами — urlencode и requests делают это автоматически. Тот же запрос через requests:

import requests

params = {"latitude": 55.75, "longitude": 37.62, "current_weather": "true"}
response = requests.get("https://api.open-meteo.com/v1/forecast", params=params, timeout=10)
weather = response.json()["current_weather"]
print("Температура в Москве:", weather["temperature"], "°C")

Разбираем настоящий ответ

Ответы API обычно вложенные: словари внутри списков внутри словарей. Главное умение — найти в них нужное. Вот пример ответа сервиса погоды на несколько дней; разберём его так же, как сделали бы с настоящим ответом:

import json

answer = """
{
  "city": "Санкт-Петербург",
  "days": [
    {"date": "2026-11-11", "temp": 4, "rain": true},
    {"date": "2026-11-12", "temp": 2, "rain": false},
    {"date": "2026-11-13", "temp": -1, "rain": false}
  ]
}
"""

data = json.loads(answer)
print("Город:", data["city"])

for day in data["days"]:
    umbrella = "возьмите зонт" if day["rain"] else "без осадков"
    print(f"{day['date']}: {day['temp']}°C, {umbrella}")

temps = [d["temp"] for d in data["days"]]
print("Средняя температура:", round(sum(temps) / len(temps), 1))

Ошибки при запросах

С интернетом всегда что-то может пойти не так: нет связи, сервер не отвечает, адрес неверный. Надёжная программа проверяет код ответа и перехватывает ошибки — вспомните урок 11:

import requests

try:
    response = requests.get("https://jsonplaceholder.typicode.com/todos/1", timeout=10)
    response.raise_for_status()      # если код 4xx или 5xx — выбросит ошибку
    data = response.json()
    print(data["title"])
except requests.exceptions.Timeout:
    print("Сервер не ответил вовремя")
except requests.exceptions.RequestException as e:
    print("Не удалось получить данные:", e)

Отправка данных: POST

GET — «дай данные», а POST — «прими данные»: так отправляют формы, сообщения, новые записи. Данные передают в json=, и requests сам превратит словарь в JSON:

import requests

new_post = {"title": "Мой первый пост", "body": "Привет из Python!", "userId": 1}
response = requests.post("https://jsonplaceholder.typicode.com/posts", json=new_post, timeout=10)

print(response.status_code)   # 201 — создано
print(response.json())

Ключи API

Многие сервисы выдают ключ API — секретную строку, по которой сервер узнаёт, кто к нему обращается. Её передают в параметрах или в заголовках запроса:

import os
import requests

api_key = os.environ.get("WEATHER_API_KEY")   # ключ хранится вне кода
headers = {"Authorization": f"Bearer {api_key}"}
response = requests.get("https://api.example.com/data", headers=headers, timeout=10)
Ключ — как пароль. Никогда не публикуйте его: не вставляйте в код, который выкладываете на GitHub, и не отправляйте в чаты. Храните ключ отдельно — например, в переменной окружения, как в примере выше.

Частые ошибки новичков

Ошибаться — нормально, так учатся все программисты. Главное — научиться читать сообщение об ошибке: Python подсказывает, что не так и в какой строке.

Одинарные кавычки в JSON

Так нельзя
import json
data = json.loads("{'city': 'Казань'}")
Правильно
import json
data = json.loads('{"city": "Казань"}')
print(data["city"])

Python скажет: json.decoder.JSONDecodeError: Expecting property name enclosed in double quotes: line 1 column 2 (char 1)

В JSON строки и ключи пишутся только в двойных кавычках. Одинарные — это синтаксис Python, а не JSON.

Забыли разобрать JSON

Так нельзя
text = '{"temp": 5}'
print(text["temp"])
Правильно
import json
text = '{"temp": 5}'
print(json.loads(text)["temp"])

Python скажет: TypeError: string indices must be integers, not 'str'

Пока JSON не разобран, это просто строка, а у строки нет ключей. Сначала json.loads(text) или response.json().

В ответе нет такого ключа

Так нельзя
import json
data = json.loads('{"temp": 5}')
print(data["temperature"])
Правильно
import json
data = json.loads('{"temp": 5}')
print(data.get("temperature", "нет данных"))

Python скажет: KeyError: 'temperature'

Названия ключей нужно брать из документации API или из настоящего ответа. Если ключа может не быть, используйте data.get("temperature").

Главное за урок

  • API — способ, которым программы обмениваются данными: запрос по адресу (URL) → ответ с кодом статуса и данными.
  • Коды: 2xx — успех, 4xx — ошибка в запросе, 5xx — ошибка сервера. 200 — всё хорошо, 404 — не найдено.
  • Данные обычно в JSON. json.loads(текст) превращает JSON в словари и списки, json.dumps — обратно.
  • requests.get(url, params=..., timeout=10) — получить данные, requests.post(url, json=...) — отправить. Устанавливается через pip.
  • Проверяйте ответ (raise_for_status, try/except) и храните ключи API в секрете.
