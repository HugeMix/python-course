Урок 1: Введение в Python

Познакомимся с языком Python, установим среду и напишем первую программу.

🎯 Цель урока

Познакомиться с языком Python, установить среду для программирования и написать первую программу.

📌 Что такое Python?

Python - это простой и понятный язык программирования, который используется для создания сайтов, игр, ботов, анализа данных, искусственного интеллекта и многого другого. Язык был создан программистом Гвидо ван Россумом, а первый релиз состоялся в 1991 году.

Главные плюсы Python: читаемый синтаксис, похожий на обычный English-текст, огромное сообщество и миллионы готовых библиотек.

🔧 Установка Python

Чтобы начать программировать, нужно установить Python:

  1. Перейди на официальный сайт: python.org.
  2. Скачай последнюю версию для своей операционной системы.
  3. Установи, поставив галочку "Add Python to PATH" - это позволит запускать Python из командной строки.

💻 Проверка установки

Открой командную строку (Windows) или терминал (Mac/Linux) и напиши: 

python --version

Если появится версия Python (например, Python 3.12.0), значит всё установлено правильно.

🚀 Первая программа - Hello World

Открой Python IDLE (устанавливается вместе с Python) или любой текстовый редактор, например VS Code, и напиши:

print("Привет, мир!")

Запусти код - если на экране появилось Привет, мир!, значит всё работает! 🎉

📢 О функции print()

  • Она выполняет одну роль: выводит переданные данные в консоль (на экран).
  • Python регистрозависим! Это значит, что print и PRiNT - это совершенно разные вещи. Команды нужно писать строго маленькими буквами.
  • Текст внутри print() нужно помещать в кавычки - одинарные 'текст' или двойные "текст".

📁 Файлы Python

Все файлы с кодом на Python имеют расширение .py. Например: my_program.py. Чтобы запустить файл, напишите в терминале: 

python my_program.py

💡 Редакторы кода

Для написания программ удобно использовать специальные редакторы:

  • Python IDLE - встроенный редактор, идеален для новичков.
  • VS Code - мощный бесплатный редактор с подсветкой синтаксиса.
  • PyCharm - профессиональная среда разработки.

🌍 Где используется Python?

Python — один из самых универсальных языков в мире. Вот пять главных областей, где он применяется:

  • Веб-разработка — такие гиганты как Instagram, YouTube и Pinterest используют Python в своей серверной части. Популярные фреймворки: Django и Flask.
  • Анализ данных — библиотеки pandas и NumPy делают Python стандартом в науке о данных. Компании Netflix и Spotify используют его для анализа поведения пользователей.
  • Искусственный интеллект и машинное обучение — библиотеки TensorFlow и PyTorch (от Google и Meta) написаны с поддержкой Python. ChatGPT от OpenAI тоже разрабатывается с его помощью.
  • Автоматизация — скрипты для автоматической обработки файлов, отправки писем, парсинга сайтов. NASA использует Python для автоматизации научных расчётов.
  • Кибербезопасность — инструменты для тестирования безопасности, анализа сети и поиска уязвимостей. Kali Linux поставляется со множеством Python-инструментов для специалистов по безопасности.

💻 Интерактивный режим Python

Python можно использовать как умный калькулятор прямо в терминале! Открой командную строку и просто напиши python (или python3 на Mac/Linux) — ты попадёшь в интерактивный режим, где каждая команда выполняется мгновенно:

>>> 2 + 2
4
>>> print("Привет!")
Привет!
>>> 10 * 5
50

Значок >>> — это приглашение ввода. Чтобы выйти из интерактивного режима, введи exit() или нажми Ctrl+Z (Windows) / Ctrl+D (Mac/Linux). Интерактивный режим отлично подходит для быстрой проверки идей и экспериментов с кодом.

🎯 Первая настоящая программа

Давай напишем программу, которая приветствует пользователя по имени. Функция input() позволяет получить текст, введённый пользователем с клавиатуры:

name = input("Как тебя зовут? ")
print("Привет, " + name + "! Добро пожаловать в мир Python!")
print("Сегодня начинается твой путь в программировании!")

Запусти программу — она спросит твоё имя и выведет персональное приветствие. Это уже настоящая интерактивная программа! Программа ждёт ввода, читает его и реагирует — именно так работают все программы в мире.
