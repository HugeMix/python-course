Введение в Python: первая программа

Узнаем, что такое программа, и напишем первую строку кода.

Цель урока

Понять, что такое программа и Python, научиться выводить текст и числа командой print(), писать комментарии и узнать, где запускать свой код.

Время: около 30 минут · 2 упражнения в уроке · тест · 3 задачи на дом

Зачем это нужно

Программа — это список команд для компьютера. Компьютер очень быстрый и никогда не устаёт, но сам ничего не придумывает: он делает ровно то, что написано в программе, и в том порядке, в каком написано.

Python (читается «пайтон») — один из самых популярных языков программирования в мире. Его выбирают для первого знакомства с программированием, потому что код на Python похож на обычные английские фразы. При этом на нём работают настоящие большие проекты:

  • сайты и приложения — часть YouTube, Instagram и Dropbox написана на Python;
  • чат-боты для Telegram и других мессенджеров;
  • искусственный интеллект и нейросети;
  • анализ данных — таблицы, графики, отчёты;
  • автоматизация — программы, которые сами переименовывают файлы, отправляют письма, собирают данные с сайтов;
  • игры — простые 2D-игры делают на библиотеке pygame.

Python придумал нидерландский программист Гвидо ван Россум, первая версия вышла в 1991 году. Сейчас используется Python 3 — именно его вы и будете изучать.

Первая программа

По традиции первая программа на любом языке выводит на экран фразу «Привет, мир!». На Python это одна строка. Нажмите «Запустить» под примером:

print("Привет, мир!")

Поздравляем — это ваша первая программа! Её можно менять прямо здесь: замените текст в кавычках на свой и снова нажмите «Запустить».

Разберём, из чего состоит эта строка:

  1. print — команда «напечатай», то есть «выведи на экран». По-английски print значит «печатать».
  2. ( ) — круглые скобки. В них пишут то, что нужно вывести.
  3. "Привет, мир!" — текст в кавычках. Кавычки показывают Python, где текст начинается и где заканчивается. Можно писать двойные "…" или одинарные '…' — главное, одинаковые с двух сторон.

Программа выполняется сверху вниз

Обычно в программе много строк. Python выполняет их по очереди: сначала первую, потом вторую и так до конца. Каждый print выводит новую строку.

print("Раз")
print("Два")
print("Три")
print("Программа закончилась")

Поменяйте строки местами и запустите снова — вывод тоже поменяется местами.

Попробуйте сами

Приветствие из двух строк

Напишите программу, которая выводит две строки: сначала Привет!, а потом Я учу Python.

Подсказка

Нужны две команды print, каждая на своей строке. Текст пишется в кавычках: print("Привет!").

Текст и числа

В print можно передавать не только текст, но и числа. Числа пишут без кавычек — тогда Python понимает, что с ними можно считать:

print(7)
print(2 + 3)
print("2 + 3")
print(10 * 60)

Посмотрите на вторую и третью строки вывода. 2 + 3 без кавычек — это пример, Python его посчитал и вывел 5. А "2 + 3" в кавычках — это просто текст, Python вывел его как есть.

Для вычислений есть знаки: + сложить, - вычесть, * умножить, / разделить. Подробно о них — в уроке 3.

Несколько значений в одном print

Если нужно вывести текст и число вместе, перечислите их через запятую. Python сам поставит между ними пробел:

print("Мне", 12, "лет")
print("В сутках", 24 * 60, "минут")
print()
print("Пустой print() выше вывел пустую строку")

Пустой print() без ничего в скобках выводит пустую строку — так удобно отделять части вывода друг от друга.

Попробуйте сами

Часы в году

Выведите две строки: Часов в сутках: 24 и Часов в году: 8760. Число 8760 не пишите вручную — пусть Python сам посчитает 365 * 24.

Подсказка

Во втором print через запятую напишите текст и вычисление: print("Часов в году:", 365 * 24).

Комментарии

Всё, что написано после знака #, Python пропускает. Такие строки называются комментариями. Их пишут для людей: чтобы объяснить, что делает код, или временно «выключить» строку, не удаляя её.

# Эта программа здоровается
print("Привет!")  # комментарий можно писать и в конце строки
# print("Эта строка не выполнится")

Где писать код

Все примеры в этом курсе можно запускать прямо на странице. Для своих программ есть редактор кода (раздел «Практика») — он тоже работает в браузере, ничего устанавливать не нужно. Этого хватит, чтобы пройти весь курс.

Когда захотите писать программы на своём компьютере:

  1. Скачайте Python с официального сайта python.org (раздел Downloads).
  2. При установке на Windows обязательно поставьте галочку Add python.exe to PATH — без неё компьютер не найдёт Python.
  3. Установите редактор кода. Для начала подойдёт Thonny (очень простой, сделан для новичков) или VS Code (им пользуются профессионалы).
  4. Создайте файл с расширением .py, например hello.py, напишите в нём код и запустите кнопкой Run в редакторе.

Проверить, что Python установлен, можно в терминале (на Windows — «Командная строка»):

python --version

Если в ответ появилась строка вроде Python 3.12.4 — всё готово. На macOS и Linux команда может называться python3.

Частые ошибки новичков

Ошибаться — нормально, так учатся все программисты. Главное — научиться читать сообщение об ошибке: Python подсказывает, что не так и в какой строке.

Команда с большой буквы

Так нельзя
Print("Привет")
Правильно
print("Привет")

Python скажет: NameError: name 'Print' is not defined

Python различает большие и маленькие буквы: print и Print для него — разные слова. Все команды Python пишутся маленькими буквами.

Текст без кавычек

Так нельзя
print(Привет)
Правильно
print("Привет")

Python скажет: NameError: name 'Привет' is not defined

Без кавычек Python думает, что Привет — это имя чего-то, что вы создали раньше, и не находит его. Текст всегда пишется в кавычках.

Забыли закрыть кавычку

Так нельзя
print("Привет)
Правильно
print("Привет")

Python скажет: SyntaxError: unterminated string literal (detected at line 1)

Кавычка открылась, но не закрылась — Python не понимает, где кончается текст. Кавычки всегда парные.

Забыли закрыть скобку

Так нельзя
print("Привет"
Правильно
print("Привет")

Python скажет: SyntaxError: '(' was never closed

Каждой открывающей скобке нужна закрывающая. Python прямо пишет: скобка «(» так и не закрылась.

Главное за урок

  • Программа — это команды для компьютера. Python выполняет их по очереди, сверху вниз.
  • print(...) выводит на экран то, что написано в скобках. Каждый print — новая строка.
  • Текст пишется в кавычках: "Привет". Числа — без кавычек, с ними можно считать: print(2 + 3).
  • Несколько значений в одном print перечисляют через запятую — между ними появится пробел.
  • Всё после # — комментарий, Python его пропускает. Команды пишутся маленькими буквами: print, а не Print.

Домашнее задание

Задачи проверяются автоматически: откройте задачу, напишите решение и нажмите «Проверить».

В этих задачах программа получает данные через input() и печатает ответ через print() — так же, как в упражнениях урока. Проверка сама подставит разные данные и сравнит ваш вывод с правильным.
  • Привет, мир!лёгкая · +1 баллНе решена
  • Визиткалёгкая · +1 баллНе решена
  • Ёлочкасредняя · +2 баллаНе решена

Задание со звёздочкой: «Открытка»

Нарисуйте в редакторе кода открытку для друга из символов: рамку из звёздочек *, внутри — поздравление и подпись. Например, так:

**********************
*  С днём рождения!  *
*     от Маши        *
**********************

Эту задачу проверяет преподаватель: отправьте ему код или покажите на занятии.
