Операторы и вычисления

Считаем на Python: арифметика, деление нацело, остаток и порядок действий.

Цель урока

Научиться считать на Python: использовать арифметические операторы, делить нацело и находить остаток, соблюдать порядок действий, округлять дробные числа и коротко изменять переменные через +=.

Время: около 40 минут · 2 упражнения в уроке · тест · 4 задачи на дом

Зачем это нужно

Почти любая программа что-то считает. Интернет-магазин складывает цены в корзине и вычитает скидку. Игра прибавляет очки и отнимает жизни. Навигатор делит расстояние на скорость, чтобы узнать время в пути.

В этом уроке вы научитесь считать на Python: всё, что умеет калькулятор, и ещё немного больше — например, делить конфеты поровну и узнавать, сколько останется.

Арифметические операторы

Знаки действий в программировании называют операторами. Вот все арифметические:

ОператорЧто делаетПримерРезультат
+сложение7 + 29
-вычитание7 - 25
*умножение7 * 214
/деление7 / 23.5
//деление нацело (целая часть)7 // 23
%остаток от деления7 % 21
**возведение в степень7 ** 249
 
price = 250
count = 3

print("Сумма:", price * count)
print("Со скидкой 100:", price * count - 100)
print("10 / 4 =", 10 / 4)
print("10 / 2 =", 10 / 2)

Заметьте: обычное деление / всегда даёт дробное число — даже 10 / 2 равно 5.0, а не 5.

Деление нацело и остаток

Операторы // и % кажутся странными, но они очень полезны. Представьте: 17 конфет делят поровну на 5 детей. Сколько получит каждый и сколько останется?

candies = 17
kids = 5

print("Каждому:", candies // kids)
print("Осталось:", candies % kids)

17 // 5 — это 3: каждый получит по 3 конфеты. 17 % 5 — это 2: две конфеты останутся. Так же переводят минуты в часы, копейки в рубли, дни в недели.

С остатком связаны два частых приёма:

  • n % 2 равно 0 у чётных чисел и 1 у нечётных — так проверяют чётность;
  • n % 10 — последняя цифра числа, а n // 10 — число без последней цифры.
n = 2024
print("Последняя цифра:", n % 10)
print("Без последней цифры:", n // 10)
print("Остаток от деления на 2:", n % 2)

Площадь и периметр комнаты

Программа получает два целых числа — длину и ширину комнаты в метрах (каждое на своей строке). Выведите две строки: Площадь: S и Периметр: P.

Подсказка

Площадь — длина умножить на ширину. Периметр — сумма всех четырёх сторон: (length + width) * 2.

Порядок действий

Python считает по тем же правилам, что и в школьной математике: сначала степень, потом умножение и деление, потом сложение и вычитание. Скобки меняют порядок.

print(2 + 3 * 4)
print((2 + 3) * 4)
print(2 * 3 ** 2)
print(100 - 10 - 5)

Если сомневаетесь, в каком порядке выполнится выражение, — поставьте скобки. Лишние скобки не мешают, а код становится понятнее.

Дробные числа и округление

Дробные числа пишутся через точку: 2.5, а не 2,5. Для округления есть команда round(): с одним числом она округляет до целого, а вторым числом можно указать, сколько оставить знаков после точки.

avg = 14 / 3
print(avg)
print(round(avg))
print(round(avg, 2))
print(abs(-7))

abs() возвращает число без знака минус (модуль числа) — пригодится, например, чтобы узнать разницу температур, не думая, какая из них больше.

Сокращённые операторы

Очень часто переменную нужно увеличить или уменьшить. Вместо score = score + 10 можно написать короче — score += 10:

Сумма цифр трёхзначного числа

Программа получает трёхзначное число, например 123. Выведите сумму его цифр: 1 + 2 + 3 = 6. Решите задачу с помощью // и %.

Подсказка

Последняя цифра — n % 10. Средняя — n // 10 % 10. Первая — n // 100.

Сравнения: ответ «да» или «нет»

Числа можно не только считать, но и сравнивать. Результат сравнения — True (правда) или False (ложь):

age = 15
print(age > 12)
print(age == 18)
print(age != 18)
print(7 % 2 == 0)

Такие ответы «да/нет» нужны, чтобы программа принимала решения. Этому посвящён следующий урок — об условиях.

Частые ошибки новичков

Ошибаться — нормально, так учатся все программисты. Главное — научиться читать сообщение об ошибке: Python подсказывает, что не так и в какой строке.

Деление на ноль

Так нельзя
total = 100
people = 0
print(total / people)
Правильно
total = 100
people = 4
print(total / people)

Python скажет: ZeroDivisionError: division by zero

На ноль делить нельзя — ни в математике, ни в Python. Проверьте, откуда в делителе взялся ноль.

Забыли превратить ввод в число

Так нельзя
a = input()
b = input()
print(a - b)
Правильно
a = int(input())
b = int(input())
print(a - b)

Python скажет: TypeError: unsupported operand type(s) for -: 'str' and 'str'

input() возвращает строки, а строки нельзя вычитать. Оберните ввод в int(). Осторожно: с + ошибки не будет, но строки склеятся: «5» + «3» = «53».

Пропустили знак умножения

Так нельзя
x = 4
print(2(x + 1))
Правильно
x = 4
print(2 * (x + 1))

Python скажет: TypeError: 'int' object is not callable

В математике можно писать 2(x + 1), а в Python знак умножения обязателен. Без него Python думает, что вы пытаетесь «вызвать» число 2 как команду.

Запятая вместо точки

Так нельзя
price = 2,5
print(price + 1)
Правильно
price = 2.5
print(price + 1)

Python скажет: TypeError: can only concatenate tuple (not "int") to tuple

Дробные числа пишутся через точку. Запись 2,5 Python понимает как два отдельных числа — 2 и 5.

Главное за урок

  • Операторы: + - * /, а ещё // (нацело), % (остаток) и ** (степень).
  • / всегда даёт дробное число: 10 / 2 равно 5.0.
  • n % 10 — последняя цифра, n // 10 — число без неё, n % 2 == 0 — проверка на чётность.
  • Порядок действий как в математике, скобки его меняют. Дробные числа — через точку, округление — round(x, 2).
  • x += 5 — короткая запись x = x + 5. Сравнения дают True или False.
