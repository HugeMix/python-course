Урок 3: Операторы в Python

Изучаем арифметические, логические операторы и операторы сравнения.

🎯 Цель урока

Познакомиться с основными операторами в Python и научиться применять их в программах.

➕ Арифметические операторы

Арифметические операторы позволяют выполнять математические действия над числами:

print(10 + 5)   # Сложение → 15
print(10 - 5)   # Вычитание → 5
print(10 * 5)   # Умножение → 50
print(10 / 5)   # Деление → 2.0 (результат всегда float!)
print(10 // 3)  # Целочисленное деление → 3 (отбрасывает дробную часть)
print(10 % 3)   # Остаток от деления → 1
print(2 ** 3)   # Возведение в степень → 8

Обратите внимание: оператор // (целочисленное деление) возвращает только целую часть. Например, 10 // 3 = 3, а не 3.333. Оператор ** - это возведение в степень (в Python не используют ^ для этого).

🔄 Операторы сравнения

Используются для сравнения значений. Всегда возвращают True или False:

print(10 > 5)    # Больше → True
print(10 < 5)    # Меньше → False
print(10 == 5)   # Равно → False
print(10 != 5)   # Не равно → True
print(10 >= 10)  # Больше или равно → True
print(10 <= 5)   # Меньше или равно → False

Важно: для проверки равенства используется двойной знак равно ==, а одинарный = - это присваивание значения переменной.

🧠 Логические операторы

Логические операторы позволяют комбинировать несколько условий:

a = True
b = False
print(a and b)   # Логическое И: True только если ОБА True → False
print(a or b)    # Логическое ИЛИ: True если хотя бы ОДНО True → True
print(not a)     # Логическое НЕ: меняет на противоположное → False

Логические операторы возвращают True или False. Правила:

  • and - правда только если оба условия истинны.
  • or - правда если хотя бы одно условие истинно.
  • not - меняет логическое состояние на противоположное: из True делает False и наоборот.

💡 Операторы присваивания

Помимо обычного =, есть сокращённые операторы присваивания:

x = 10
x += 5   # То же самое что x = x + 5 → x станет 15
x -= 3   # x = x - 3 → x станет 12
x *= 2   # x = x * 2 → x станет 24
x //= 4  # x = x // 4 → x станет 6

📐 Приоритет операторов

Как и в математике, Python выполняет операторы в определённом порядке: сначала скобки, затем степень, затем умножение и деление, и наконец сложение и вычитание. Запомни аббревиатуру БСУС — Скобки, Степень, Умножение/деление, Сложение/вычитание:

# Приоритет операторов (как в математике)
print(2 + 3 * 4)     # 14, а не 20 (умножение раньше)
print((2 + 3) * 4)   # 20 (скобки меняют порядок)
print(2 ** 3 + 1)    # 9 (степень раньше сложения)
print(10 / 2 + 3)    # 8.0

# Совет: используй скобки если не уверен
result = (10 + 5) * (2 - 1)
print(result)        # 15

Если ты не уверен в порядке вычислений — просто добавь скобки. Это делает код понятнее и защищает от ошибок.

🧮 Практический пример: калькулятор ИМТ

Применим арифметику на практике — вычислим индекс массы тела (ИМТ). Это реальная формула: вес делим на квадрат роста в метрах. Заодно познакомимся с функцией round() для округления:

# Калькулятор индекса массы тела (ИМТ)
weight = float(input("Введи вес в кг: "))
height = float(input("Введи рост в метрах (например 1.75): "))

bmi = weight / (height ** 2)
bmi = round(bmi, 1)  # Округляем до 1 знака

print(f"Твой ИМТ: {bmi}")

if bmi < 18.5:
    print("Недостаток веса")
elif bmi < 25:
    print("Норма — отлично!")
elif bmi < 30:
    print("Избыток веса")
else:
    print("Ожирение")

Условия (if/elif/else) мы подробно изучим в следующем уроке — этот пример показывает, куда мы движемся. Уже сейчас видно, как операторы помогают строить реальные полезные программы.

🔗 Короткое замыкание в логике

Логические операторы and и or работают «лениво» — они останавливаются, как только результат становится очевидным. Это называется короткое замыкание (short-circuit evaluation):

x = 10
# and останавливается на первом False
result = x > 5 and x < 20  # True
result = x > 15 and x < 20  # False (не проверяет x < 20)

# or останавливается на первом True
name = ""
display_name = name or "Аноним"  # "Аноним" — если name пустая строка
print(display_name)

Приём значение or "по_умолчанию" очень популярен в Python. Если первое значение «ложное» (пустая строка, 0, None), Python берёт второе. Это элегантная замена длинным if/else.
