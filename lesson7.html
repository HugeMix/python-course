Функции

Создаём свои команды: пишем код один раз и вызываем, сколько нужно.

Цель урока

Научиться создавать свои функции через def, передавать им данные через параметры, возвращать результат через return, задавать значения по умолчанию и понимать, где «живут» переменные.

Время: около 45 минут · 2 упражнения в уроке · тест · 4 задачи на дом

Зачем это нужно

Вы уже пользовались готовыми функциями: print(), input(), len(), round(). Каждая — это кусок кода с именем: вызвали по имени — он выполнился. Вам не нужно знать, как len() считает элементы, достаточно написать len(список).

В этом уроке вы научитесь создавать свои функции. Это нужно, чтобы:

  • не повторять один и тот же код в разных местах — написали один раз, вызываете сколько угодно;
  • делить большую программу на понятные части: посчитать_скидку(), показать_меню(), сохранить_результат();
  • исправлять ошибку в одном месте, а не искать все копии кода по программе.

Первая функция: def

Функция создаётся словом def (от англ. define — «определить»):

  1. слово def, имя функции и круглые скобки;
  2. двоеточие в конце строки;
  3. тело функции — команды с отступом 4 пробела.
def say_hello():
    print("Привет!")
    print("Рад вас видеть")

say_hello()
say_hello()

Строки с def только описывают функцию — сами по себе они ничего не выводят. Код внутри выполняется, когда функцию вызывают: пишут её имя со скобками. Здесь функцию вызвали дважды — и приветствие появилось дважды.

Параметры: данные для функции

Функции можно передавать данные. В скобках при создании пишут параметры — имена, под которыми функция получит значения. При вызове в скобках пишут сами значения — аргументы:

def greet(name):
    print(f"Привет, {name}!")

greet("Анна")
greet("Максим")

def show_sum(a, b):
    print(a, "+", b, "=", a + b)

show_sum(2, 3)
show_sum(10, -4)

При вызове greet("Анна") параметр name получает значение «Анна». Аргументы передаются по порядку: в show_sum(2, 3) первое число попадает в a, второе — в b.

return: функция возвращает результат

Пока наши функции только печатали. Но чаще функция должна посчитать и отдать результат, чтобы программа могла с ним дальше работать: сохранить в переменную, сравнить, передать в другую функцию. Для этого есть return:

def square(n):
    return n * n

result = square(5)
print(result)
print(square(3) + square(4))

if square(7) > 40:
    print("Больше сорока")

return делает две вещи: отдаёт значение туда, где функцию вызвали, и сразу завершает функцию — строки после return уже не выполняются.

print или return? print показывает значение на экране, но программа его не получает. return отдаёт значение программе. Если функция что-то считает — почти всегда нужен return. Функция без return возвращает специальное значение None — «ничего».
def add_print(a, b):
    print(a + b)

def add_return(a, b):
    return a + b

x = add_print(2, 3)
y = add_return(2, 3)
print("x =", x)
print("y =", y)

Функция-приветствие

Допишите функцию greet(name): она должна возвращать строку Привет, ИМЯ!. Остальная программа уже написана: она читает имя и печатает то, что вернула функция.

Подсказка

Вместо pass напишите return f"Привет, {name}!". Не используйте print внутри функции — нужно именно вернуть строку.

Несколько return и условия

В функции может быть несколько return — в разных ветках условия. Сработает тот, до которого дойдёт выполнение:

def grade(score):
    if score >= 90:
        return 5
    if score >= 70:
        return 4
    if score >= 50:
        return 3
    return 2

print(grade(95), grade(75), grade(55), grade(10))

Здесь не нужен elif: если score >= 90, функция вернёт 5 и закончится — до следующих проверок дело не дойдёт.

Значения по умолчанию

Параметру можно задать значение по умолчанию. Тогда при вызове его можно не указывать:

def power(base, exp=2):
    return base ** exp

print(power(5))
print(power(2, 10))
print(power(base=3, exp=3))

Последняя строка показывает именованные аргументы: можно прямо написать, какому параметру какое значение. Так понятнее, когда параметров много. Параметры со значением по умолчанию всегда пишут после обычных.

Вернуть несколько значений

Функция может вернуть сразу несколько значений через запятую — Python упакует их в кортеж, а при вызове их удобно разложить по переменным:

def min_max(numbers):
    return min(numbers), max(numbers)

low, high = min_max([7, 2, 9, 4])
print("Минимум:", low)
print("Максимум:", high)

Цена со скидкой

Допишите функцию final_price(price, discount=10): она возвращает цену после скидки в процентах, округлённую до целого (round). Если скидку не указали — она 10%. Программа читает цену и скидку и печатает две строки: цену с указанной скидкой и цену со скидкой по умолчанию.

Подсказка

Цена после скидки: price * (100 - discount) / 100. Оберните это в round(...) и верните через return.

Область видимости

Переменные, созданные внутри функции, — локальные: они живут только пока функция работает и снаружи не видны. Это хорошо: функции не мешают друг другу, даже если внутри у них переменные с одинаковыми именами.

def make_total():
    total = 100
    print("Внутри функции total =", total)

total = 5
make_total()
print("Снаружи total =", total)

Внутри функции появилась своя переменная total, а внешняя осталась равна 5. Правило хорошего тона: всё, что нужно функции, передавайте через параметры, а результат отдавайте через return.

Ещё три приёма

Эти возможности не обязательно использовать сразу, но они часто встречаются в чужом коде.

Любое количество аргументов — *args. Звёздочка перед параметром собирает все переданные значения в кортеж:

def total(*numbers):
    return sum(numbers)

print(total(1, 2))
print(total(5, 10, 15, 20))

Короткая функция — lambda. Функцию из одного выражения можно записать в одну строку. Чаще всего так задают правило сортировки:

words = ["арбуз", "кот", "яблоко", "ёж"]
words.sort(key=lambda w: len(w))
print(words)

Рекурсия — функция, которая вызывает саму себя. Важно, чтобы был случай, когда она останавливается, иначе вызовы будут бесконечными:

def countdown(n):
    if n == 0:
        print("Старт!")
        return
    print(n)
    countdown(n - 1)

countdown(3)

Частые ошибки новичков

Ошибаться — нормально, так учатся все программисты. Главное — научиться читать сообщение об ошибке: Python подсказывает, что не так и в какой строке.

Вызвали до создания

Так нельзя
say_hi()

def say_hi():
    print("Привет")
Правильно
def say_hi():
    print("Привет")

say_hi()

Python скажет: NameError: name 'say_hi' is not defined

Python читает программу сверху вниз и на первой строке ещё не знает такой функции. Сначала def, потом вызов.

print вместо return

Так нельзя
def add(a, b):
    print(a + b)

result = add(2, 3) + 1
Правильно
def add(a, b):
    return a + b

result = add(2, 3) + 1
print(result)

Python скажет: TypeError: unsupported operand type(s) for +: 'NoneType' and 'int'

Функция напечатала 5, но ничего не вернула, то есть вернула None. А к None нельзя прибавить число. Нужен return.

Не передали аргумент

Так нельзя
def greet(name):
    return "Привет, " + name

print(greet())
Правильно
def greet(name="друг"):
    return "Привет, " + name

print(greet())

Python скажет: TypeError: greet() missing 1 required positional argument: 'name'

Функция ждёт один аргумент, а её вызвали с пустыми скобками. Передайте значение или задайте параметру значение по умолчанию.

Локальная переменная снаружи

Так нельзя
def calc():
    answer = 42

calc()
print(answer)
Правильно
def calc():
    answer = 42
    return answer

result = calc()
print(result)

Python скажет: NameError: name 'answer' is not defined

answer существует только внутри функции. Чтобы получить значение снаружи, верните его через return.

Главное за урок

  • Функция — именованный кусок кода. Создаётся через def имя(параметры):, выполняется при вызове имя(аргументы).
  • return отдаёт результат и завершает функцию. Без return функция возвращает None.
  • print показывает значение на экране, return отдаёт его программе — это разные вещи.
  • Параметры по умолчанию: def power(base, exp=2). Можно вызывать с именами: power(base=3, exp=3).
  • Переменные внутри функции локальные — снаружи их не видно. Данные передавайте через параметры и return.
