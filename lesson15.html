Итоговый проект: список дел

Собираем всё изученное в одно настоящее приложение.

Цель урока

Собрать из всего изученного полноценную программу — список дел с меню, сохранением в файл и защитой от ошибок; научиться планировать проект, делить его на функции и узнать, как пишут аккуратный код.

Время: около 60 минут · 2 упражнения в уроке · тест · 3 задачи на дом

Зачем это нужно

Вы прошли переменные, условия, циклы, списки, функции, словари, файлы, обработку ошибок и классы. По отдельности это кирпичики. Настоящая программа получается, когда их складывают вместе.

В этом уроке вы шаг за шагом соберёте полноценное приложение — список дел (to-do list). Оно умеет добавлять дела, показывать их, отмечать выполненные, удалять и — главное — сохраняет всё в файл, так что дела не пропадают после закрытия программы. Именно так и работают профессиональные программисты: сначала план, потом маленькие шаги, и каждый шаг сразу проверяется.

План проекта

  1. Решить, как хранить дела в программе.
  2. Написать функции для каждого действия: добавить, показать, отметить.
  3. Сделать меню, в котором пользователь выбирает действие.
  4. Научить программу сохранять дела в файл и загружать их при запуске.
  5. Защитить программу от неправильного ввода.

Шаг 1. Как хранить дела

У каждого дела есть название и отметка «выполнено или нет». Удобно хранить дело как словарь, а все дела — как список словарей:

tasks = [
    {"title": "Купить хлеб", "done": False},
    {"title": "Сделать уроки", "done": True},
]

tasks.append({"title": "Позвонить бабушке", "done": False})

print("Всего дел:", len(tasks))
print("Первое дело:", tasks[0]["title"])
print("Выполнено ли второе:", tasks[1]["done"])

Шаг 2. Функции

Каждое действие — отдельная функция с понятным именем. Так код легко читать и исправлять. Для нумерованного вывода пригодится enumerate: он выдаёт в цикле сразу номер и элемент. start=1 — чтобы нумерация начиналась с единицы, как привычно людям:

def add_task(tasks, title):
    tasks.append({"title": title, "done": False})

def show_tasks(tasks):
    for i, t in enumerate(tasks, start=1):
        mark = "✓" if t["done"] else " "
        print(f"{i}. [{mark}] {t['title']}")

def mark_done(tasks, number):
    tasks[number - 1]["done"] = True

my_tasks = []
add_task(my_tasks, "Купить хлеб")
add_task(my_tasks, "Сделать уроки")
add_task(my_tasks, "Погулять с собакой")
mark_done(my_tasks, 2)
show_tasks(my_tasks)

Строка mark = "✓" if t["done"] else " " — это короткое условие в одну строку: «галочка, если дело выполнено, иначе пробел». А в mark_done вычитается единица, потому что пользователь считает дела с 1, а индексы списка — с 0.

Шаг 3. Меню

Программа должна работать, пока пользователь не решит выйти. Это знакомый приём while True + break из урока 5. В каждом повторе показываем пункты меню, читаем выбор и вызываем нужную функцию.

while True:
    print("1 — добавить, 2 — показать, 0 — выход")
    choice = input("Выберите: ")
    if choice == "1":
        add_task(tasks, input("Что нужно сделать? "))
    elif choice == "2":
        show_tasks(tasks)
    elif choice == "0":
        break
    else:
        print("Нет такого пункта")

Шаг 4. Сохранение в файл

Каждое дело записываем в файл отдельной строкой: сначала 1 или 0 (выполнено или нет), потом черта | и название. При запуске программа читает файл и восстанавливает список. Если файла ещё нет (первый запуск), ловим FileNotFoundError и начинаем с пустого списка.

def save_tasks(tasks):
    with open("todo.txt", "w", encoding="utf-8") as f:
        for t in tasks:
            f.write(("1" if t["done"] else "0") + "|" + t["title"] + "\n")

split("|", 1) при чтении разрезает строку только по первой черте — на случай, если черта встретится в названии дела.

Шаг 5. Вся программа

Соединяем всё вместе и добавляем защиту: номер дела может оказаться не числом или числом вне списка — функция ask_number проверяет и то и другое. Запустите программу: ввод уже подставлен — добавим два дела, посмотрим список, отметим первое и попробуем удалить дело по неправильному номеру.

FILE = "todo.txt"


def load_tasks():
    """Читает дела из файла. Если файла ещё нет — пустой список."""
    tasks = []
    try:
        with open(FILE, encoding="utf-8") as f:
            for line in f:
                done, title = line.rstrip("\n").split("|", 1)
                tasks.append({"title": title, "done": done == "1"})
    except FileNotFoundError:
        pass
    return tasks


def save_tasks(tasks):
    with open(FILE, "w", encoding="utf-8") as f:
        for t in tasks:
            f.write(("1" if t["done"] else "0") + "|" + t["title"] + "\n")


def show_tasks(tasks):
    if not tasks:
        print("Список пуст")
        return
    for i, t in enumerate(tasks, start=1):
        mark = "✓" if t["done"] else " "
        print(f"{i}. [{mark}] {t['title']}")


def ask_number(tasks):
    """Спрашивает номер дела. Возвращает индекс в списке или None."""
    try:
        n = int(input("Номер дела: "))
    except ValueError:
        print("Нужно ввести число")
        return None
    if 1 <= n <= len(tasks):
        return n - 1
    print("Нет дела с таким номером")
    return None


def main():
    tasks = load_tasks()
    while True:
        print("\n1 — добавить, 2 — показать, 3 — выполнено, 4 — удалить, 0 — выход")
        choice = input("Выберите: ")
        if choice == "1":
            title = input("Что нужно сделать? ").strip()
            if title:
                tasks.append({"title": title, "done": False})
                save_tasks(tasks)
        elif choice == "2":
            show_tasks(tasks)
        elif choice == "3":
            i = ask_number(tasks)
            if i is not None:
                tasks[i]["done"] = True
                save_tasks(tasks)
        elif choice == "4":
            i = ask_number(tasks)
            if i is not None:
                removed = tasks.pop(i)
                save_tasks(tasks)
                print("Удалено:", removed["title"])
        elif choice == "0":
            print("До встречи!")
            break
        else:
            print("Нет такого пункта")


if __name__ == "__main__":
    main()

Запустите пример ещё раз: дела из прошлого запуска загрузятся из файла, и список станет длиннее. Чтобы поиграть с программой по-настоящему, скопируйте её в редакторе кода или запустите на компьютере.

Последние строки if __name__ == "__main__": main() — принятое в Python оформление: «если этот файл запустили как программу — вызвать main()». Если же файл подключат как модуль через import, меню не запустится само, а функции можно будет использовать в другой программе.

Статистика дел

Программа получает число N, а потом N строк. Каждая строка — дело: в начале +, если оно выполнено, или -, если нет, потом пробел и название. Выведите Выполнено: X из N. Если выполнены все — выведите второй строкой Все дела сделаны!

Подсказка

Заведите счётчик done = 0. В цикле читайте строку и проверяйте line.startswith("+"). После цикла — вывод и условие if done == n:.

Как писать хороший код

Код читают гораздо чаще, чем пишут, — и другие люди, и вы сами через месяц. У Python есть общепринятые правила оформления — PEP 8. Главное из них:

  • отступ — 4 пробела;
  • имена переменных и функций — маленькими буквами через подчёркивание (show_tasks), классов — с большой буквы (TodoList);
  • пробелы вокруг = и знаков действий: total = price * count;
  • понятные имена: tasks, а не t1; is_done, а не flag;
  • одна функция — одно дело; если функция не помещается на экран, её стоит разделить;
  • комментарии объясняют, зачем код, а не пересказывают, что он делает.

Частые ошибки новичков

Ошибаться — нормально, так учатся все программисты. Главное — научиться читать сообщение об ошибке: Python подсказывает, что не так и в какой строке.

Номер дела вне списка

Так нельзя
tasks = ["Купить хлеб", "Сделать уроки"]
number = 3
print(tasks[number - 1])
Правильно
tasks = ["Купить хлеб", "Сделать уроки"]
number = 3
if 1 <= number <= len(tasks):
    print(tasks[number - 1])
else:
    print("Нет дела с таким номером")

Python скажет: IndexError: list index out of range

Пользователь может ввести любой номер. Перед обращением проверьте, что он от 1 до len(tasks).

Ввели не число

Так нельзя
number = int(input("Номер дела: "))
Правильно
try:
    number = int(input("Номер дела: "))
except ValueError:
    print("Нужно ввести число")

Python скажет: ValueError: invalid literal for int() with base 10: 'пять'

Вместо цифр пользователь написал слово. Оберните int(input()) в try/except ValueError.

Опечатка в ключе словаря

Так нельзя
task = {"title": "Купить хлеб", "done": False}
print(task["titel"])
Правильно
task = {"title": "Купить хлеб", "done": False}
print(task["title"])

Python скажет: KeyError: 'titel'

Ключи словаря нужно писать точно так же, как при создании. Опечатки в ключах — одна из самых частых ошибок в проектах.

Что можно добавить

Проект готов, но его можно развивать бесконечно — это отличная тренировка:

  • приоритеты: важные дела показывать первыми (сортировка через sort(key=...));
  • сроки: дата для каждого дела и пометка «просрочено» (урок 14);
  • категории: «учёба», «дом», «покупки» и фильтр по ним;
  • класс TodoList вместо отдельных функций (урок 13) — это задача из домашнего задания;
  • окно с кнопками вместо текстового меню — библиотека tkinter уже есть в Python;
  • Telegram-бот, который хранит ваши дела, — библиотека aiogram.

Идеи для следующих шагов после курса — на странице «Что дальше?».

Главное за урок

  • Большую программу делают по плану и маленькими шагами, проверяя каждый шаг.
  • Данные проекта удобно хранить списком словарей: [{"title": ..., "done": False}].
  • Каждое действие — отдельная функция с понятным именем. enumerate(список, start=1) даёт номер и элемент.
  • Меню — это while True с if/elif и break. Данные сохраняются в файл и загружаются при запуске.
  • Любой ввод пользователя проверяйте: try/except для чисел, проверка диапазона для номеров. Оформляйте код по PEP 8.
