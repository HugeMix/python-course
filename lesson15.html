Урок 15: Итоговый проект - To-Do List

Примените все полученные знания и создайте своё первое полноценное приложение.

🎯 Задача

Создайте консольное приложение на Python, которое поможет пользователю вести список дел (To-Do List) с сохранением данных в файл.

📌 Описание проекта

Программа должна позволять:

  • Добавлять задачи
  • Просматривать список задач
  • Удалять выполненные задачи
  • Сохранять список в файл и загружать его при следующем запуске

💻 Пример кода

import json

def load_tasks():
    try:
        with open("tasks.json", "r", encoding="utf-8") as file:
            return json.load(file)
    except FileNotFoundError:
        return []

def save_tasks(tasks):
    with open("tasks.json", "w", encoding="utf-8") as file:
        json.dump(tasks, file, ensure_ascii=False, indent=4)

def main():
    tasks = load_tasks()
    while True:
        print("\n1. Добавить задачу")
        print("2. Показать список задач")
        print("3. Удалить задачу")
        print("4. Выйти")
        choice = input("Выберите действие: ")

        if choice == "1":
            task = input("Введите новую задачу: ")
            tasks.append(task)
            save_tasks(tasks)
        elif choice == "2":
            print("\nВаш список дел:")
            for i, task in enumerate(tasks, 1):
                print(f"{i}. {task}")
        elif choice == "3":
            num = int(input("Введите номер задачи для удаления: ")) - 1
            if 0 <= num < len(tasks):
                tasks.pop(num)
                save_tasks(tasks)
            else:
                print("Некорректный номер!")
        elif choice == "4":
            break
        else:
            print("Неверный ввод, попробуйте снова.")

if __name__ == "__main__":
    main()

🔍 Какие знания курса задействованы?

  • Функции (def) - load_tasks(), save_tasks(), main()
  • Списки - tasks.append(), tasks.pop(), перебор с enumerate()
  • Файлы - with open(), чтение и запись JSON
  • Обработка ошибок - try-except FileNotFoundError
  • Циклы - бесконечный while True с выходом через break
  • Условия - if-elif-else
  • Строки - f-строки для форматирования вывода

🔁 Паттерн while True + break - бесконечное меню

В итоговом проекте главное меню реализовано через конструкцию while True. Цикл выполняется бесконечно, пока пользователь не выберет «Выйти» - тогда срабатывает break и цикл останавливается:

while True:
    choice = input("Введите 1, 2 или 3: ")
    if choice == "3":
        break  # Выход из бесконечного цикла
    print("Продолжаем...")

Это стандартный паттерн для консольных меню в Python.

🔢 Функция enumerate() - нумерованный перебор

Функция enumerate(список) позволяет одновременно получать индекс и значение каждого элемента при переборе - очень удобна для вывода нумерованных списков:

tasks = ["Купить молоко", "Позвонить маме", "Сделать зарядку"]
for i, task in enumerate(tasks, 1):  # start=1 начинает нумерацию с 1
    print(f"{i}. {task}")
# Выведет:
# 1. Купить молоко
# 2. Позвонить маме
# 3. Сделать зарядку

Именно так в проекте выводится пронумерованный список задач: for i, task in enumerate(tasks, 1).

🌟 Расширение проекта: фильтрация и поиск

Улучшим базовый менеджер задач: добавим приоритеты, дату создания, статус выполнения и возможность фильтровать задачи. Каждая задача теперь хранится как словарь.

import json
import datetime

TASKS_FILE = "tasks.json"

def load_tasks():
    try:
        with open(TASKS_FILE, "r", encoding="utf-8") as f:
            return json.load(f)
    except (FileNotFoundError, json.JSONDecodeError):
        return []

def save_tasks(tasks):
    with open(TASKS_FILE, "w", encoding="utf-8") as f:
        json.dump(tasks, f, ensure_ascii=False, indent=2)

def add_task(title, priority="средний"):
    tasks = load_tasks()
    task = {
        "id": len(tasks) + 1,
        "title": title,
        "priority": priority,
        "done": False,
        "created": datetime.datetime.now().strftime("%d.%m.%Y")
    }
    tasks.append(task)
    save_tasks(tasks)
    print(f"Добавлено: {title} [{priority}]")

def show_tasks(filter_done=None, priority=None):
    tasks = load_tasks()
    for task in tasks:
        if filter_done is not None and task["done"] != filter_done:
            continue
        if priority and task["priority"] != priority:
            continue
        status = "+" if task["done"] else "o"
        print(f"{status} [{task['id']}] {task['title']} — {task['priority']}")

def complete_task(task_id):
    tasks = load_tasks()
    for task in tasks:
        if task["id"] == task_id:
            task["done"] = True
            save_tasks(tasks)
            print(f"Задача '{task['title']}' выполнена!")
            return
    print("Задача не найдена")

📁 Структура профессионального проекта

Когда проект вырастает за пределы одного файла, важно правильно организовать структуру папок. Вот стандартная структура Python-проекта:

my_project/
│
├── main.py           # Точка входа
├── requirements.txt  # Зависимости (pip freeze > requirements.txt)
├── README.md         # Описание проекта
│
├── src/              # Исходный код
│   ├── __init__.py
│   ├── tasks.py      # Логика задач
│   └── utils.py      # Вспомогательные функции
│
├── data/             # Данные
│   └── tasks.json
│
└── tests/            # Тесты
    └── test_tasks.py

Назначение папок: src/ содержит весь бизнес-код, разбитый по модулям; data/ хранит файлы данных отдельно от кода; tests/ содержит автоматические тесты; requirements.txt позволяет любому разработчику установить все зависимости одной командой pip install -r requirements.txt.

🔧 Git: контроль версий

Git — это система контроля версий, которая отслеживает каждое изменение в вашем коде. Она незаменима при работе в команде и позволяет безопасно экспериментировать: если что-то сломалось, всегда можно вернуться к рабочей версии.

# Инициализация нового репозитория
git init

# Добавить все файлы в отслеживание
git add .

# Создать коммит (снимок версии)
git commit -m "Первая версия менеджера задач"

# Просмотр истории
git log --oneline

# Создать ветку для новой функции
git checkout -b feature/search

# Вернуться на главную ветку
git checkout main

# Загрузить на GitHub (после создания репозитория на github.com)
git remote add origin https://github.com/username/my_project.git
git push -u origin main
