Переменные и типы данных

Учим программу запоминать данные и получать их от пользователя.

Цель урока

Научиться создавать переменные и менять их значения, различать типы данных, получать ввод от пользователя через input(), превращать текст в числа и собирать красивый вывод с помощью f-строк.

Время: около 40 минут · 2 упражнения в уроке · тест · 4 задачи на дом

Зачем это нужно

Программе постоянно нужно что-то запоминать: имя пользователя, счёт в игре, цену товара в корзине, сколько попыток осталось. Для этого существуют переменные.

Переменную удобно представлять как коробку с наклейкой. На наклейке — имя, а внутри лежит значение. По имени программа в любой момент находит коробку и достаёт то, что в ней лежит.

Создаём переменную

Чтобы создать переменную, напишите её имя, знак = и значение:

name = "Анна"
age = 14

print(name)
print(age)
print(name, age)

Знак = в программировании значит не «равно», а «положить в»: строку age = 14 читают так: «положить 14 в переменную age». Обратите внимание: в print(name) нет кавычек — нам нужно не слово «name», а то, что лежит в переменной.

Значение можно менять

Переменная потому так и называется, что её значение может меняться. Когда вы кладёте в коробку новое значение, старое пропадает.

score = 0
print("Начало игры, очки:", score)

score = 10
print("Нашли монету, очки:", score)

score = score + 5
print("Победили врага, очки:", score)

Строка score = score + 5 сначала берёт то, что лежит в score (10), прибавляет 5 и кладёт результат (15) обратно в score.

Как называть переменные

Имя переменной можно придумать любое, но есть правила:

ПравилоМожноНельзя
Буквы, цифры и знак подчёркиванияscore, level_2my-score, цена$
Не начинать с цифрыplayer11player
Без пробелов — вместо них подчёркиваниеfirst_namefirst name
Не использовать слова Pythonmy_listif, for, print

Python различает большие и маленькие буквы: age и Age — две разные переменные. Принято писать имена маленькими латинскими буквами, а слова разделять подчёркиванием: user_name, total_price. И давайте понятные имена: через неделю вы сами не вспомните, что хранится в x2, а с apples_count всё ясно.

Типы данных

Значения бывают разных видов — их называют типами. Тип определяет, что со значением можно делать: числа можно складывать и умножать, а у текста — искать буквы или менять регистр.

ТипЧто хранитПример
intцелое число14, -3, 0
floatдробное число (через точку!)3.14, -0.5, 2.0
strстрока — любой текст в кавычках"Привет", "42"
boolлогическое значение: да или нетTrue, False

Узнать тип значения можно командой type():

print(type(14))
print(type(3.14))
print(type("Привет"))
print(type("14"))
print(type(True))

Важно: "14" в кавычках — это строка, а не число. Для Python это просто два символа, «1» и «4», и считать с ними нельзя.

Ввод с клавиатуры: input()

Команда input() ждёт, пока пользователь что-нибудь напечатает, и возвращает этот текст. Обычно его сразу кладут в переменную. В примерах на этой странице ввод уже подставлен за вас — он написан справа от кнопки «Запустить».

name = input("Как вас зовут? ")
print("Приятно познакомиться,", name)

Текст в скобках у input("Как вас зовут? ") — это подсказка, её видит пользователь. Её можно и не писать: input().

Превращаем текст в число

Есть важная особенность: input() всегда возвращает строку, даже если ввели цифры. Посмотрите, что получится:

age = input()
print(type(age))
print(age + age)

Вместо 28 вышло 1414: две строки просто склеились. Чтобы получить число, текст нужно преобразовать:

КомандаЧто делаетПример
int(...)превращает в целое числоint("14") → 14
float(...)превращает в дробное числоfloat("2.5") → 2.5
str(...)превращает в строкуstr(14) → "14"
 
age = int(input())
print("Сейчас вам", age)
print("Через год будет", age + 1)

Запись int(input()) выполняется изнутри наружу: сначала input() получает текст «14», потом int() превращает его в число 14.

Программа получает целое число. Выведите это число, умноженное на 2.

Подсказка

Сначала превратите ввод в число: n = int(input()). Потом выведите n * 2.

Собираем текст: + и f-строки

Строки можно склеивать знаком +. Но склеить строку с числом нельзя — число сначала превращают в строку через str():

name = "Анна"
age = 14

print("Привет, " + name + "!")
print("Вам " + str(age) + " лет")

Это работает, но плюсы и кавычки легко перепутать. Поэтому чаще используют f-строки: перед кавычкой ставят букву f, а переменные пишут прямо внутри текста в фигурных скобках { }. Python сам подставит значения:

name = "Анна"
age = 14

print(f"Привет, {name}!")
print(f"Вам {age} лет, а через 5 лет будет {age + 5}")

Бейдж участника

Программа получает две строки: сначала имя, потом фамилию. Выведите бейдж в формате Участник: Фамилия Имя — фамилия идёт первой.

Подсказка

Несколько переменных в одной строке

Можно создать сразу несколько переменных, перечислив их через запятую. А ещё так удобно поменять значения местами:

x, y = 3, 8
print("x =", x, "y =", y)

x, y = y, x
print("После обмена: x =", x, "y =", y)

Частые ошибки новичков

Ошибаться — нормально, так учатся все программисты. Главное — научиться читать сообщение об ошибке: Python подсказывает, что не так и в какой строке.

Опечатка в имени

Так нельзя
name = "Аня"
print(nmae)
Правильно
name = "Аня"
print(name)

Python скажет: NameError: name 'nmae' is not defined

Python не нашёл переменную nmae — её никто не создавал. Проверьте, что имя написано так же, как при создании, буква в букву.

Имя начинается с цифры

Так нельзя
1place = "Аня"
print(1place)
Правильно
place1 = "Аня"
print(place1)

Python скажет: SyntaxError: invalid decimal literal

Имя переменной не может начинаться с цифры. Перенесите цифру в конец или замените словом.

Пробел в имени

Так нельзя
my age = 14
Правильно
my_age = 14

Python скажет: SyntaxError: invalid syntax

Пробелов в именах быть не может — Python видит два отдельных слова. Используйте подчёркивание.

Склеили строку с числом

Так нельзя
age = int(input())
print("Вам " + age + " лет")
Правильно
age = int(input())
print(f"Вам {age} лет")

Python скажет: TypeError: can only concatenate str (not "int") to str

Знак + умеет склеивать только строку со строкой. Используйте f-строку или превратите число в строку через str(age).

Главное за урок

  • Переменная — коробка с именем. x = 5 значит «положить 5 в x». Новое значение заменяет старое.
  • Имена: латинские буквы, цифры и _, не с цифры и без пробелов. age и Age — разные переменные.
  • Основные типы: int (целое), float (дробное), str (текст), bool (True/False). Тип показывает type().
  • input() всегда возвращает строку. Для чисел: int(input()) или float(input()).
  • Текст с переменными удобно собирать f-строкой: f"Привет, {name}!".
