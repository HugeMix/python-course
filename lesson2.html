Урок 2: Переменные и типы данных

Разберёмся с переменными, типами данных и их преобразованием.

Цель урока

Научиться работать с переменными, понимать их типы и уметь преобразовывать данные из одного типа в другой.

Что такое переменная?

Переменная - это «контейнер» для хранения данных. В Python переменную можно создать, просто присвоив ей значение с помощью знака =:

x = 5          # Создали переменную x и присвоили ей число 5
name = "Анна"  # Создали переменную name и присвоили ей строку "Анна"

В отличие от многих других языков, в Python не нужно объявлять тип переменной - он определяется автоматически по значению.

Правила именования переменных

  • Имя может содержать только буквы, цифры и символ подчёркивания (_).
  • Имя не может начинаться с цифры: 1var - недопустимо, вызовет ошибку.
  • Рекомендуется писать переменные строчными буквами, разделяя слова подчёркиванием (стиль snake_case): my_variable, user_name.
  • Python чувствителен к регистру: Name и name - это разные переменные!

Основные типы данных

Python автоматически определяет тип переменной. Вот четыре основных типа:

  • int (целые числа): age = 20
  • float (числа с плавающей точкой): height = 1.75
  • str (строки - текст в кавычках): city = "Москва"
  • bool (логические значения True/False): is_student = True

Функция type()

Узнать тип переменной можно с помощью встроенной функции type():

print(type("10"))   # Выведет <class 'str'>
print(type(5))      # Выведет <class 'int'>
print(type(3.14))   # Выведет <class 'float'>
print(type(True))   # Выведет <class 'bool'>

Преобразование типов

Иногда нужно преобразовать один тип данных в другой. Для этого используют специальные функции:

  • int() - преобразует в целое число
  • float() - в число с плавающей точкой
  • str() - в строку
  • bool() - в логическое значение
num = "10"       # Это строка
num = int(num)   # Теперь это число (целое)
print(num + 5)   # Выведет 15

Конкатенация строк

Если сложить две строки оператором +, они «склеятся» - это называется конкатенацией. Это НЕ математическое сложение! 

print(str(5) + '5')  # Результатом будет '55', а не 10!

Поэтому при работе с числами важно убедиться, что они действительно числа, а не строки.

Ввод данных от пользователя

Чтобы пользователь мог ввести данные с клавиатуры, используют функцию input(). Она всегда возвращает строку, поэтому при необходимости нужно конвертировать тип:

name = input("Как тебя зовут? ")
print("Привет,", name)

age = int(input("Сколько тебе лет? "))  # Конвертируем строку в число
print("Через 10 лет тебе будет:", age + 10)

Множественное присваивание

Python позволяет присваивать значения нескольким переменным одновременно — это делает код короче и выразительнее:

# Несколько переменных в одной строке
x, y, z = 10, 20, 30
print(x, y, z)  # 10 20 30

# Обмен значений без третьей переменной
a, b = 5, 8
a, b = b, a
print(a, b)  # 8 5

# Одно значение нескольким переменным
x = y = z = 0

Обмен значений через a, b = b, a — одна из фишек Python, которая удивляет тех, кто пришёл из других языков. В C или Java для этого нужна третья временная переменная!

Преобразование типов на практике

Самый частый случай преобразования типов — это работа с вводом пользователя. Всё что вводит пользователь через input(), Python считает строкой, даже если введены цифры:

# Всё что пользователь вводит — это строка
age_str = input("Введи свой возраст: ")  # Строка, например "25"
age = int(age_str)                        # Теперь число

# Можно объединить:
year = int(input("Введи год рождения: "))
current_year = 2024
age = current_year - year
print("Тебе примерно", age, "лет")

Обрати внимание: если пользователь введёт не число, а, например, «двадцать пять», функция int() выдаст ошибку ValueError. Обработку таких ситуаций изучим позже.

Частые ошибки с типами

Новички часто сталкиваются с TypeError при попытке сложить строку и число. Вот как это происходит и как исправить:

# ОШИБКА: нельзя складывать строку и число
# age = "25"
# print("Вам " + age + " лет")  # Это OK — строка + строка
# print("Вам " + 25 + " лет")   # TypeError!

# ПРАВИЛЬНО: либо преобразовать, либо использовать f-строку
age = 25
print("Вам " + str(age) + " лет")  # Преобразование
print(f"Вам {age} лет")            # f-строка (удобнее!)

F-строки (f-strings) — современный и самый удобный способ вставлять переменные в текст. Просто поставь f перед кавычкой и оберни переменную в фигурные скобки {}.

  • Попробуй преобразовать возраст в строку с помощью str(), а рост в целое число с помощью int().

  • Используй множественное присваивание: в одной строке создай переменные город, страна и население и выведи их.

  • Попробуй специально вызвать TypeError: напиши print("Возраст: " + 25) без преобразования, запусти программу, прочитай сообщение об ошибке и исправь её двумя способами — через str() и через f-строку.
