Классы и объекты (ООП)

Создаём свои типы данных: персонажей, счета, книги — со своими данными и умениями.

Цель урока

Понять, что такое классы и объекты, научиться создавать классы с атрибутами и методами, разобраться с self и __init__, сделать красивый вывод через __str__ и использовать наследование.

Время: около 50 минут · 2 упражнения в уроке · тест · 4 задачи на дом

Зачем это нужно

Представьте игру: в ней десятки персонажей. У каждого есть имя, здоровье и уровень, и каждый умеет атаковать, лечиться и повышать уровень. Можно хранить всё это в отдельных переменных и словарях, но скоро в коде будет не разобраться.

Объектно-ориентированное программирование (ООП) предлагает другой подход: описать один раз, что такое «персонаж» — какие у него данные и что он умеет, — а потом создавать сколько угодно персонажей по этому описанию. Так устроены почти все большие программы: игры, сайты, приложения.

Класс и объект

Два главных слова ООП:

  • Класс — чертёж, шаблон. Например, «Собака»: у неё есть кличка и возраст, она умеет лаять.
  • Объект — конкретная вещь, созданная по чертежу. Шарик, 3 года, и Бобик, 5 лет, — два объекта класса «Собака».

Вы уже пользовались объектами: каждая строка — объект класса str, каждый список — объект класса list. А upper() и append() — их методы, то есть то, что они умеют.

class Dog:
    def __init__(self, name, age):
        self.name = name
        self.age = age

    def bark(self):
        print(f"{self.name}: Гав!")

sharik = Dog("Шарик", 3)
bobik = Dog("Бобик", 5)

sharik.bark()
bobik.bark()
print(bobik.name, "—", bobik.age, "лет")

Разбираем по шагам

  1. class Dog: — создаём класс. Имена классов принято писать с большой буквы.
  2. def __init__(self, name, age): — особый метод, который Python вызывает при создании объекта. Здесь объект получает свои начальные данные. Вокруг слова init — по два подчёркивания с каждой стороны.
  3. self.name = name — сохраняем значение в атрибут объекта. Атрибуты — это переменные, которые принадлежат объекту.
  4. def bark(self): — метод, то есть функция внутри класса: то, что объект умеет делать.
  5. Dog("Шарик", 3) — создаём объект. Python вызывает __init__ и передаёт ему «Шарик» и 3.

Что такое self

self — это «я сам», тот объект, с которым сейчас работает метод. Когда вы пишете sharik.bark(), Python сам передаёт sharik в параметр self. Поэтому внутри метода self.name — это кличка именно того пса, которого попросили залаять.

Правило простое: self — всегда первый параметр каждого метода, а к атрибутам внутри методов обращаются через self.

Класс Кот

Допишите класс Cat: при создании он получает кличку и возраст, а метод describe() возвращает строку Кот КЛИЧКА, возраст: N. Программа читает кличку и возраст, создаёт кота и печатает его описание.

Подсказка

В __init__: self.name = name и self.age = age. В describe: return f"Кот {self.name}, возраст: {self.age}".

Методы меняют объект

Методы могут не только что-то показывать, но и менять атрибуты объекта. Именно так объект «живёт»: копит деньги, теряет здоровье, получает уровень.

class BankAccount:
    def __init__(self, owner, balance=0):
        self.owner = owner
        self.balance = balance

    def deposit(self, amount):
        self.balance += amount

    def withdraw(self, amount):
        if amount > self.balance:
            print("Недостаточно средств")
            return False
        self.balance -= amount
        return True

acc = BankAccount("Аня", 100)
acc.deposit(50)
acc.withdraw(500)
acc.withdraw(30)
print(acc.owner, "— на счёте", acc.balance)

Обратите внимание: проверка «хватает ли денег» спрятана внутри метода. Тот, кто пользуется счётом, просто вызывает withdraw и не может случайно уйти в минус. Скрывать внутреннее устройство и давать пользоваться объектом только через методы называется инкапсуляцией. Атрибуты, которые не нужно трогать снаружи, принято начинать с подчёркивания: self._balance.

Счётчик

Допишите класс Counter: атрибут value сначала равен 0, метод plus() увеличивает его на 1, метод minus() уменьшает на 1, но не ниже нуля. Программа читает строку из плюсов и минусов, например ++-+, нажимает соответствующие кнопки и печатает итоговое значение.

Подсказка

В plus: self.value += 1. В minus: уменьшайте, только если self.value > 0.

Красивый вывод: __str__

Если напечатать объект, Python покажет что-то вроде <__main__.Book object at 0x…>. Чтобы print выводил понятный текст, добавьте метод __str__ — он должен вернуть строку:

class Book:
    def __init__(self, title, author):
        self.title = title
        self.author = author

    def __str__(self):
        return f"«{self.title}» — {self.author}"

book = Book("Незнайка на Луне", "Николай Носов")
print(book)

Методы с двумя подчёркиваниями с обеих сторон называют магическими: Python вызывает их сам в особых ситуациях. __init__ — при создании, __str__ — при выводе. Есть и другие, например __len__ — для len(объект).

Наследование

Класс можно создать на основе другого. Новый класс получает все атрибуты и методы родителя и может добавить свои или изменить старые. Так не нужно копировать общий код:

class Animal:
    def __init__(self, name):
        self.name = name

    def speak(self):
        return "..."

    def introduce(self):
        print(f"Я {self.name}. {self.speak()}")

class Dog(Animal):
    def speak(self):
        return "Гав!"

class Cat(Animal):
    def speak(self):
        return "Мяу!"

for pet in [Dog("Шарик"), Cat("Мурка"), Animal("Ёжик")]:
    pet.introduce()

class Dog(Animal): значит «Dog — это разновидность Animal». У Dog нет своего __init__ и introduce — они взяты у родителя. А метод speak переопределён: у каждого животного свой голос.

Если дочернему классу нужен свой __init__, родительский вызывают через super():

class Animal:
    def __init__(self, name):
        self.name = name

class Bird(Animal):
    def __init__(self, name, can_fly):
        super().__init__(name)
        self.can_fly = can_fly

penguin = Bird("Пингвин", False)
print(penguin.name, "умеет летать:", penguin.can_fly)

Частые ошибки новичков

Ошибаться — нормально, так учатся все программисты. Главное — научиться читать сообщение об ошибке: Python подсказывает, что не так и в какой строке.

Забыли self в методе

Так нельзя
class Dog:
    def bark():
        print("Гав")

Dog().bark()
Правильно
class Dog:
    def bark(self):
        print("Гав")

Dog().bark()

Python скажет: TypeError: Dog.bark() takes 0 positional arguments but 1 was given

Python всегда передаёт в метод сам объект первым аргументом. Если параметра self нет, принять его некуда.

Забыли self. перед атрибутом

Так нельзя
class Dog:
    def __init__(self, name):
        self.name = name

    def hello(self):
        print("Я", name)

Dog("Рекс").hello()
Правильно
class Dog:
    def __init__(self, name):
        self.name = name

    def hello(self):
        print("Я", self.name)

Dog("Рекс").hello()

Python скажет: NameError: name 'name' is not defined

Внутри метода name — это обычная переменная, а она здесь не создана. Атрибут объекта — self.name.

Одно подчёркивание вместо двух

Так нельзя
class Dog:
    def _init_(self, name):
        self.name = name

rex = Dog("Рекс")
Правильно
class Dog:
    def __init__(self, name):
        self.name = name

rex = Dog("Рекс")
print(rex.name)

Python скажет: TypeError: Dog() takes no arguments

Python ищет метод именно __init__ — по два подчёркивания с каждой стороны. Метод _init_ для него обычный, и создать объект с аргументом не получается.

Не передали данные при создании

Так нельзя
class Dog:
    def __init__(self, name):
        self.name = name

rex = Dog()
Правильно
class Dog:
    def __init__(self, name="Безымянный"):
        self.name = name

rex = Dog()
print(rex.name)

Python скажет: TypeError: Dog.__init__() missing 1 required positional argument: 'name'

__init__ ждёт кличку, а объект создали с пустыми скобками. Передайте значение или задайте параметру значение по умолчанию.

Главное за урок

  • Класс — чертёж (class Dog:), объект — вещь, созданная по нему (Dog("Шарик", 3)). Объектов одного класса может быть сколько угодно.
  • __init__ вызывается при создании объекта и задаёт начальные атрибуты: self.name = name.
  • Методы — функции внутри класса. Первый параметр всегда self, к атрибутам обращаются через self.
  • Методы могут менять атрибуты — так объект «живёт». __str__ задаёт, как объект выглядит в print.
  • Наследование: class Dog(Animal): получает всё от родителя, может добавить своё или переопределить. Родительский __init__ — через super().
