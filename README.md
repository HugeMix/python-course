# PythonBasic — курс Python для начинающих

Бесплатный интерактивный курс Python на русском языке: 16 уроков с тестами, тренажёр задач
с автоматической проверкой, онлайн-компилятор, шпаргалка, глоссарий и сертификат.

Сайт: https://hugemix.github.io/python-course/

Это статический сайт: только HTML, CSS и JavaScript, без сервера и без сборки.
Python выполняется прямо в браузере с помощью [Pyodide](https://pyodide.org/).

## Как запустить локально

Страницы «Задачи» и «Python Online» запускают Python в отдельном потоке (Web Worker).
Chrome и Edge не разрешают это для файлов, открытых двойным щелчком (`file://`),
поэтому сайт нужно открывать через локальный сервер:

```bash
python3 -m http.server 8000
```

Затем откройте в браузере http://localhost:8000.

Нужен интернет: Pyodide, редактор CodeMirror и подсветка кода загружаются с CDN.

## Как устроено

**Тесты в уроках** лежат в `script.js`, в объекте `quizData`. Ключ — имя файла урока.
Вопрос с вариантами:

```js
{ question: "Текст вопроса", options: ["A", "B", "C"], correct: 1, explanation: "Почему верно B" }
```

`correct` — номер правильного варианта, считая с нуля. Варианты на странице перемешиваются.

Вопрос с вводом кода:

```js
{ question: "Текст вопроса", type: "code", correct: ["вариант 1", "вариант 2"], explanation: "..." }
```

Ответ сравнивается с вариантами целиком и с учётом регистра.
Пробелы вокруг знаков и скобок не важны, кавычки можно писать любые, но парные.
Урок засчитывается при 70% правильных ответов.

**Задачи** лежат в `tasks_data.js`. Код ученика выполняется в чистом пространстве имён,
после него запускается `testCode`. Задача решена, только если тест дошёл до строки
`__task_passed__ = True` (её ставят перед сообщением об успехе).
Чтобы запретить встроенную функцию или потребовать конструкцию, в тестах есть помощники:

```python
assert not __uses_call__("max"), "Нельзя использовать max()"
assert __uses_node__("Try"), "Используйте try-except"
```

**Режим «Урок по созвону».** На каждом уроке есть кнопка «Провести урок по созвону»:
урок открывается на весь экран слайдами (один раздел — один слайд) крупным шрифтом.
Листать — стрелками ← →, пробелом, кнопками внизу или свайпом на телефоне; `F` — во весь экран,
`Esc` — выйти, `A−`/`A+` — размер шрифта. Ссылка вида `lesson3.html#present` сразу открывает урок слайдами.
Код режима — функции `initPresentationMode` и `openPresentation` в `script.js`.

**Прогресс** хранится только в браузере ученика (`localStorage`):

| Ключ | Что хранит |
|---|---|
| `quiz_results` | Пройденные уроки: `{"lesson1.html": true, ...}` |
| `course_completed_at` | Дата окончания курса (для сертификата) |
| `solved_tasks` | Решённые задачи |
| `saved_code_<id>` | Автосохранённый код задачи |
| `cert_name`, `cert_number` | Имя и номер в сертификате |
| `theme` | Светлая или тёмная тема |
| `present_slide_<урок>`, `present_scale` | Слайд, на котором остановились, и размер шрифта в режиме «Урок по созвону» |

Так как прогресс хранится в браузере, блокировку уроков и сертификат при желании
можно обойти. Для учебного сайта без регистрации это нормально.

## Как добавить урок

1. Скопируйте любой `lessonN.html`, поменяйте номер, заголовки, `canonical` и `og:url`.
2. Добавьте файл в массив `lessonsList` в начале `script.js` и тесты в `quizData`.
3. Добавьте карточку урока в `python-basic.html`.
4. Добавьте адрес в `sitemap.xml`.
5. Если меняется общее число уроков, поправьте `LESSONS_TOTAL` в `certificate.html`
   и тексты «16 уроков» на страницах.
